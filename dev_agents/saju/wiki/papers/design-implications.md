# 설계 시사점

기준일: 2026-10-30 · 상태: 초안

이 페이지는 [국내 학술 지형](academic-landscape-korea.md), [실증 연구](empirical-studies.md), [과학적 검증](validity-skepticism.md), [LLM과 명리](llm-fortune.md)에서 확인한 **사실**과 우리가 정할 **제안**을 나눠 적는다. 제안은 모두 사용자 확인 전 후보다.

## 요약

- 그럴듯함은 정확성과 상관없이 생긴다. "나를 위한 것"이라는 믿음, 좋은 말, 권위가 수용을 키운다(사실). 그래서 그럴듯함은 바넘 문장이 아니라 "근거가 보이는 구체 문장"에서 얻는다(제안).
- 나쁜 운을 믿으면 실제 결과가 나빠질 수 있다. 불길한 출생년+질병 조합을 가진 중국계 미국인이 1.3~4.9년 일찍 사망했다(Phillips 외 1993, 사실). 건강·사망·사고 단정은 금지한다(제안).
- LLM은 규칙 적용(사례 판단)에 약하고 반복하면 답이 바뀐다(사실). 판단은 코드로, 같은 입력엔 같은 결과(제안).
- 이용자는 LLM 운세를 정서적 지지로 쓰고, 원하는 답이 나올 때까지 다시 묻는다(사실). 재미와 결정 조언을 구분하고, 다시 뽑기로 운을 바꿀 수 없게 한다(제안).

## 설계 규칙 후보 — 제안

### R1. 바넘 문장 감지 (근거 F1, F2, F3)
- **교차 프로필 유사도**: 서로 다른 골든 사주 20개 이상으로 리포트를 만들고, 문장 임베딩 유사도가 임계치를 넘는 문장은 "누구에게나 맞는 말"로 표시. 임계치는 실험으로 정한다.
- **근거 추적 필수**: 모든 해석 문장에 근거 ID(예: `day_stem:甲`, `clash:子午`)를 붙인다. 근거 없는 문장은 생성 실패로 처리.
- **모호 표현 감점**: "때로는", "언젠가", "변화가 있을 수 있다", "주변 사람" 같은 반증 불가 표현 목록.
- **양면 문장 감점**: "외향적이지만 혼자 있는 시간도 필요" 같은 양쪽 다 맞는 문장 패턴.
- **사용자 입력 되돌려주기 감지**: 사용자가 적은 고민을 해석인 척 되풀이하는 문장 감지(콜드 리딩 구조).

### R2. 구체성과 근거 노출 (근거 F1, F2)
- 그럴듯함의 원천을 "여덟 글자 중 어디에서 나왔는지"를 보여주는 데 둔다. 예: "올해 丁未의 未가 일지 丑과 충(沖)합니다 → 고전은 이를 거처·관계 변동으로 읽습니다".
- "오직 당신만을 위한", "정확히 꿰뚫는" 같은 관련성 과장 문구 금지 — 바넘 수용을 키우는 장치 그 자체다.
- 효과 측정: 근거 노출이 신뢰에 주는 효과를 운세 맥락에서 직접 잰 논문은 **미확인**. A/B 실험 후보로 둔다(근거 표시 vs 미표시, 신뢰도·불안 측정).

### R3. 나쁜 운 표현 (근거 F5, F6, F2, F10)
- 금지: 사망·질병·사고·이혼·파산 단정. 날짜를 찍은 흉사 예고.
- 허용: "고전은 이 구성을 ○○에 주의할 시기로 해석합니다" + 할 수 있는 행동 한 가지.
- 비율: 주의 문장은 반드시 대응 행동과 짝. 좋은 말만 남기지도 않는다(호의성만 높이면 바넘이 커짐, F1).
- 2026 병오·2027 정미 같은 띠·간지 해의 "흉년" 프레임 금지(F6, 1966 병오 출생 25% 감소).

### R4. 일관성과 재질문 (근거 F8, F9, F10)
- 같은 생년월일시 + 같은 해 → 같은 리포트(캐시). "다시 보기"는 문장 표현만 바꾸고 판단은 바꾸지 않는다.
- 계산·판단은 코드. LLM은 판단된 결과를 문장으로만.
- 시각 모름 → 시주 의존 문장 생략. 틀린 입력이 해석을 크게 흔든다(F9).

### R5. 윤리 — 취약 사용자와 의존 (근거 F5, F7, F10, F11)
- 자해·자살·중병·법적 위기 키워드 입력 시 운세 대신 상담 기관 안내(문구·기관은 별도 확정).
- 하루 조회 횟수나 같은 질문 반복에 제한·안내(재질문 의존 방지).
- 투자·의료·법률·결혼 같은 큰 결정은 "운세로 정하지 마세요" 고정 문구.
- 민감 정보(건강, 연인 실명) 입력 경고(Lin 외 2026 설계 제안).

### R6. 엔터테인먼트 고지 (근거 F3, F4, F12)
- "전통 명리 해석에 기반한 재미·성찰용 콘텐츠이며, 과학적으로 검증된 예측이 아닙니다" 수준의 고지.
- 위치: 결과 첫 화면 하단 + 공유 이미지. 리포트 본문에서 "과학적으로 입증", "논문으로 증명" 표현 금지.
- 사내 PoC 문구의 법적 검토 필요 여부는 **미확인**.

## 미확인 · 열린 질문

- 근거 노출이 운세 신뢰·만족에 주는 효과를 직접 잰 연구.
- 부정 운세가 불안을 얼마나 높이는지 잰 실험(운세 맥락).
- 바넘 유사도 임계치(골든 프로필 실험 필요).
- 한국 이용자 대상 LLM 운세 연구.

# 지지 합·충·형·파·해 (+원진)

기준일: 2026-10-30 · 상태: 초안

## 요약 (5줄 이내)
- 지지끼리의 관계는 **합**(육합·삼합·반합·방합·암합)과 **마찰**(충·형·파·해·원진)으로 나뉜다.
- 고전 정의(삼명통회 권2)는 육합 6쌍, 삼합 4국, 삼형(寅巳申·丑戌未·子卯)과 자형(辰午酉亥), 육해 6쌍, 충(일곱 번째 지지)을 적는다. 파 6쌍과 원진 6쌍은 고전 원문에서 같은 형태로 확인하지 못했다.
- 적천수는 "支神只以沖為重"(지지는 충을 가장 무겁게 본다)고 적는다 → 우선순위는 **충 > 합 > 형 > 해·파·원진**을 후보로 한다.
- 2027 세운 未는 원국의 午와 육합, 丑과 충, 戌과 형·파, 子와 해·원진, 卯·亥와 삼합 일부, 巳·午와 방합 일부, 寅과 귀문(일부 학파)을 맺는다.

## 개념 — 정의, 표, 계산 규칙

### 합
| 종류 | 구성 | 결과 오행 | 성립 조건(근거) |
|---|---|---|---|
| 육합 | 子丑 寅亥 卯戌 辰酉 巳申 午未 | 土 木 火 金 水, 午未는 土(bazi) 또는 火(한국어 위키백과) | 한 음 한 양의 짝: "一陰一陽和而謂之合"(삼명통회 권2 「論支元六合」). 원문은 쌍별 화 오행을 적지 않음 |
| 삼합 | 申子辰(水) 亥卯未(木) 寅午戌(火) 巳酉丑(金) | 각 국 오행 | 세 글자가 다 있어야 국: "三字缺一則化不成局"(삼명통회 권2 「論支元三合」) |
| 반합 | 삼합 중 두 글자. 왕지(子午卯酉) 포함 쌍(예: 卯未, 亥卯) | 같은 오행, 약하게 | 고전 원문은 세 글자 원칙. 반합은 현대 통용. 생지+왕지 > 왕지+고지 > 생지+고지(가합·공합) 순이며, 왕지 없는 쌍은 합으로 안 보는 학파도 있음(한국어 위키백과) |
| 방합(삼회) | 寅卯辰(木) 巳午未(火) 申酉戌(金) 亥子丑(水) | 계절 오행 | 같은 계절 세 글자. 왕지가 없어도 성립한다는 설명이 있음(한국어 위키백과, 출처 표기 없음) |
| 암합 | 지장간 본기끼리 천간합: 子戌, 丑寅, 寅未, 卯申, 午亥 등 | — | 정의가 학파마다 다름(bazi `AnheDef` NORMAL/EXTENDED/盲派 3종). 기본값에서 제외 후보 |

### 마찰
| 종류 | 구성 | 근거 |
|---|---|---|
| 충 | 子午 丑未 寅申 卯酉 辰戌 巳亥 | "地支取七位為沖"(삼명통회 권2 「論沖擊」). 같은 절에 충이 대체로 흉하지만 서로 생하는 경우 좋을 수 있다는 서술 |
| 삼형 | 寅巳申(무은지형), 丑戌未(시세지형) | 삼명통회 권2 「論三刑」 |
| 상형 | 子卯(무례지형) | 같은 절 |
| 자형 | 辰辰 午午 酉酉 亥亥 | 같은 절 "辰午酉亥…自刑" |
| 육해(穿) | 子未 丑午 寅巳 卯辰 申亥 酉戌 | 삼명통회 권2 「論六害」 |
| 파 | 子酉 卯午 辰丑 未戌 寅亥 巳申 | 현대 통용 6쌍(bazi `DIZHI_PO`). 삼명통회 「論沖擊」의 破는 破印·破財처럼 **무엇을 깨뜨리는지**의 분류이고, 권3의 破煞은 4쌍뿐이라고 bazi 주석이 밝힘 → 6쌍 원문 **미확인** |
| 원진 | 子未 丑午 寅酉 卯申 辰亥 巳戌 | 한국 실무 신살(한국어 위키백과 「신살」). 삼명통회 권3 「論元辰」은 성별·연간 음양으로 "沖前一位/沖後一位"를 찾는 다른 계산이어서 쌍 표와 같은 것인지 **미확인** |
| 귀문(관살) | 子酉 丑午 寅未 卯申 辰亥 巳戌 | 한국 실무(한국어 위키백과 「신살」, 월지-일지·일지-시지 기준). 고전 출처 **미확인**. → [신살](shinsal.md)에서 다룸 |

### 형의 성립 조건 — 학파 차이
- STRICT: 寅巳申·丑戌未는 **세 글자가 모두** 있어야 삼형.
- LOOSE: 두 글자만 있어도 형(방향: 丑→戌→未→丑, 寅→巳→申→寅). bazi 기본값은 LOOSE.
- 세운이 원국 두 글자와 합쳐 셋을 채우는 경우(예: 원국 丑·戌 + 세운 未)는 두 방식 모두 삼형.

### 우선순위와 동시 성립 (후보 규칙)
1. 적천수 「地支論」: "支神只以沖為重，刑與害兮動不動" → 충을 가장 무겁게.
2. 같은 두 글자에 여러 관계가 겹치면 모두 사실로 기록한다(예: 未戌 = 형 + 파, 子未 = 해 + 원진, 丑未 = 충 + 형(LOOSE)).
3. 합과 충이 같은 글자에 동시에 걸리면(예: 원국 午·丑에 세운 未) "합충 동시"로 표시하고 어느 쪽이 이기는지 판정하지 않는다(판정 규칙은 학파마다 다름, **미확인**).
4. 삼합·방합 완성(3글자) > 육합 > 반합.

### 학술 논문 (RISS 초록 확인, 2026-10-30)
- **합이 성립하기 어려운 경우**: 이재승(2021, 인문사회21)은 고전 문헌 검토로 ① 떨어진 합(요합)·다투는 합(쟁합)·합과 충이 겹친 경우는 합이 이루어지기 어렵고, ② 지지합의 결과 오행이 천간에 드러나 있으면 합력이 강하며, ③ 월지가 왕지(旺支)인 삼합·방합의 합력은 합·형·충이 함께 있어도 유지된다고 정리한다. 지지 합력 차이를 4등급으로 나누지만 등급표는 초록에 없음. 저자 스스로 사례 수가 적다고 밝힘.
- **발동 조건**: 윤훈근(2014, 원광대 석사)은 합충형해파가 "관계 조건"(쌍이 맞음)만으로는 작용하지 않고 "동기부여"가 있어야 발동한다고 본다. 해(害)는 합과 충의 작용 관계에서, 형·파는 합과 합이 섞일 때 생긴다고 설명하고, 여럿이 섞이는 것은 대체로 불리하다고 결론. 관계들 사이 명시적 우선순위는 초록에 없음.
- **지지합의 원리**: 김만태(2012, 철학논집)는 육합을 음지·양지의 짝으로 보고 일월회합설·월건월장설·황도12궁설로 설명한다. 삼합(같은 기운)과 방합(계절·방위)을 구분하고, 삼합의 최초 문헌 흔적을 『회남자』 「천문훈」으로 본다. 『회남자』는 지금과 달리 午·戌·寅의 **土국**을 따로 둔다(午=생지, 戌=왕지, 寅=고지). 午未 합의 오행은 초록에 없음.
- **실증 시도**: 남직호(2019, 박사, 349명: 이혼 177·비이혼 172)는 로지스틱 회귀에서 **지충(지지충) 개수가 늘수록 이혼 가능성이 높아지는 방향**, 천극은 반대 방향이라고 보고. 남성 辰酉합(p=0.010), 여성 酉丑 반합(p=0.048)이 이혼군에서 많았다. 횡단·상관 연구이고 여러 변수를 동시에 검정해 우연 유의 가능성이 있다. 원진은 검정 변수에 없다.
- **형식화**: 전세연(2026)은 합충 성립은 규칙화 가능하지만 **합충의 희기(좋고 나쁨)는 용신·격국 판단에 의존**(IIb)한다고 분류(초록 확인).

## 해석에서 쓰이는 방식 — 신년운세 문장으로 이어지는 경로
1. 코드가 세운 지지 未와 원국 4지지(+대운 지지)의 관계를 모두 찾는다. 원국 지지가 놓인 자리(연·월·일·시)도 함께 넘긴다.
2. 삼명통회 「論太歲」: 세운이 월주를 충하면 반드시 화가 있다("若歲運沖月必禍")는 고전 서술이 있지만, 서비스 문장은 "변동이 큰 해로 보는 전통" 수준으로 완화한다.
3. 일지(배우자 자리)와의 충·합은 관계 주제로, 월지와는 일·직장 주제로 연결하는 것이 통용 궁위 해석이다.

### 2027 세운 未 × 원국 지지 (바로 쓰는 표)
`scratchpad/calc/wiki_rel/wei.py`로 bazi 2.4.0 규칙표 대조. 원진·귀문은 한국어 위키백과 「신살」 쌍 표 기준.

| 원국 지지 | 未와의 관계 | 비고 |
|---|---|---|
| 子 | **해**(子未), **원진**(子未) | |
| 丑 | **충**(丑未), 형(LOOSE: 未→丑) | 원국에 戌도 있으면 丑戌未 삼형 완성 |
| 寅 | 귀문(寅未, 한국 실무), 암합(寅未, 한국어 위키백과 일부 정의) | bazi 암합 정의에는 없음 |
| 卯 | **반합**(卯未, 木), 亥卯未 삼합 일부 | 원국에 亥도 있으면 삼합 木국 완성 |
| 辰 | 없음 | |
| 巳 | 방합 일부(巳午未), 巳未 拱(午를 끼고) | 원국에 午도 있으면 방합 火 완성 |
| 午 | **육합**(午未), 방합 일부 | |
| 未 | 같은 글자(복음·伏吟으로 부르는 관행) | 未는 자형이 아님 |
| 申 | 없음 | |
| 酉 | 없음 | |
| 戌 | **형**(LOOSE: 戌→未), **파**(未戌) | 원국에 丑도 있으면 삼형 완성 |
| 亥 | 삼합 일부(亥卯未), 亥未 공합(卯 결여) | 왕지 없는 쌍 — 반합 인정 여부 학파 차이 |

예시 A(원국 午·巳·辰·巳, `research/00_입문.md`): 未 + 午 = 육합, 未 + 巳·午 = 巳午未 방합(火) 완성.

## 우리 적용 — 해석표 YAML 후보 (사용자 확인 전)
```yaml
branch_relations:
  liuhe: {pairs: [子丑, 寅亥, 卯戌, 辰酉, 巳申, 午未], report_element: false}
  sanhe: {require_all_three: true, half_combine: wangji_only}   # 반합은 왕지 포함 쌍만
  fanghe: {require_all_three: true}
  chong: [子午, 丑未, 寅申, 卯酉, 辰戌, 巳亥]
  xing: {mode: strict, include: [寅巳申, 丑戌未, 子卯, self:[辰, 午, 酉, 亥]]}
  hai: [子未, 丑午, 寅巳, 卯辰, 申亥, 酉戌]
  po: off                      # 근거 약함 — 사실 목록에서 제외 후보
  wonjin: korean_practice_flag # 한국 실무 표시용, 문장 비중 낮게
  anhe: off
  priority: [sanhe_or_fanghe_complete, chong, liuhe, xing, half_combine, hai]
  scope: [natal_4_branches, daewoon_branch, liunian_branch]
  forbidden: [충=사고·이별 단정, 형=소송·수술 단정]
```
- **검토 필요(2026-10-30, 논문 반영 메모 — 값은 바꾸지 않음)**: ① 지금은 합·충 동시 성립 시 승패를 판정하지 않는다. 이재승(2021) 초록의 "합충 겹치면 합 불성립", "월지 왕지 삼합은 충이 있어도 유지"를 규칙 후보로 넣을지 사용자 결정(본문 근거 확인 후). ② `priority`에서 충을 육합보다 위에 둔 것은 위 "합충 겹치면 합이 어렵다"는 정리와 같은 방향. ③ 남직호(2019)의 지충–이혼 상관은 상관 연구이므로 `forbidden: 충=이별 단정`은 그대로 유지하는 것이 맞다고 봄 — 이 연구를 근거로 문장 톤을 바꾸지 않는다.

## 미확인 · 열린 질문
- 파 6쌍, 원진 6쌍, 귀문 쌍의 고전 출처.
- 합과 충이 동시에 걸릴 때 어느 쪽을 우선하는지(탐합망충 등) — 원문 미확인. 부분 확인: 이재승(2021) 초록은 "합충이 겹치면 합이 이루어지기 어렵다", "월지 왕지 삼합은 충이 있어도 유지"라고 정리. 탐합망충 원문·고순영(2017, 경기대 석사 「命理學 十二地支의 변화에 관한 硏究: 合·沖을 중심으로」 — 저자 요청으로 원문·초록 비공개) 미확인.
- ~~지지 관계를 다룬 KCI·RISS 논문~~ → 합충형해파는 확인됨(이재승 2021, 윤훈근 2014, 김만태 2012, 남직호 2019 초록). 원진은 도출 원리만 확인(일지 삼합과 지지충, 김만태 2025 초록 → [신살](shinsal.md)). 원진·귀문을 주제로 한 논문은 RISS "원진살" 학위논문 검색에서 궁합 논문 2건만 나와 미열람 — 남음.

# 공망 (空亡, 순공)

기준일: 2026-10-30 · 상태: 초안

## 요약 (5줄 이내)
- 천간 10개와 지지 12개를 짝지으면 열 개씩 묶은 한 순(旬)마다 지지 2개가 남는다. 이 남는 2개가 그 순의 **공망**이다.
- 삼명통회 권3 「論空亡」: "以甲旬盡處曰空亡". 생일(일주)이 속한 순의 공망이 가장 중요하다고 적는다.
- 학파 차이: **일주 기준**(기본) / **연주 기준** / 둘 다. 해석에서도 "비어 힘이 약해진다"는 기본 뜻 외에, 충·합으로 풀린다는 설(해공)은 현대 관행이며 원문 확인 못 함.
- 2027 세운 未는 일주가 **甲申~癸巳 순**인 사람에게 공망 자리다. 세운 丁未 자체의 순 공망은 寅·卯.

## 개념 — 정의, 표, 계산 규칙
코드 검증: `scratchpad/calc/wiki_rel/wei.py` — bazi 2.4.0 `ShenshaRules.KONGWANG`(60갑자 전체)에서 생성.

| 순(旬) | 공망 | 이 순에 속한 일주 |
|---|---|---|
| 甲子순 | 戌亥 | 甲子 乙丑 丙寅 丁卯 戊辰 己巳 庚午 辛未 壬申 癸酉 |
| 甲戌순 | 申酉 | 甲戌 乙亥 丙子 丁丑 戊寅 己卯 庚辰 辛巳 壬午 癸未 |
| 甲申순 | 午未 | 甲申 乙酉 丙戌 丁亥 戊子 己丑 庚寅 辛卯 壬辰 癸巳 |
| 甲午순 | 辰巳 | 甲午 乙未 丙申 丁酉 戊戌 己亥 庚子 辛丑 壬寅 癸卯 |
| 甲辰순 | 寅卯 | 甲辰 乙巳 丙午 丁未 戊申 己酉 庚戌 辛亥 壬子 癸丑 |
| 甲寅순 | 子丑 | 甲寅 乙卯 丙辰 丁巳 戊午 己未 庚申 辛酉 壬戌 癸亥 |

- 계산: 일주의 60갑자 번호 n(甲子=0)에서 순 머리 = n − (n mod 10). 그 순 머리 지지에서 10칸 뒤, 11칸 뒤 지지가 공망.
- 예시 A(일주 庚辰): 甲戌순 → 공망 申·酉 (`research/00_입문.md` 값과 일치).

## 학파·문헌별 차이
| 쟁점 | 입장 | 근거 |
|---|---|---|
| 기준 기둥 | 일주(생일 순)가 가장 중요 | 삼명통회 권3 「論空亡」 "生日旬中空亡，極緊" |
| | 연주 기준도 씀. 연주로 세운 예: "甲子至戊辰，以戌為空亡；己巳至癸酉，以亥為空亡" | 같은 절 — 한 순을 반으로 나눠 공망 1개씩 배정하는 **반순(半旬) 세분법**도 실려 있음 |
| | 연·일 둘 다 | bazi `_ANCHOR_CHOICES` 주석이 『五行精紀』의 "年日所在" 인용을 근거로 듦(원문 직접 미확인) |
| 단 2지지 vs 1지지 | 순공 2지지 / 양간·음간 또는 반순으로 1지지만 | 위 삼명통회 서술. bazi는 2지지만 구현 |
| 오행별 예외 | 연해자평 「論六親總篇」 "金空則鳴，火空則發，水空則流" — 금·화·수는 비면 오히려 좋다는 서술 | 연해자평 |
| 해공(풀림) | 충·합·형을 받으면 공망이 풀린다 | 현대 실무 관행으로 알려짐, 원문 **미확인**. 이원우(2020) 목차에 "현대 명리서의 공망 해석 — 해공" 절이 있어 현대 명리서 쪽 개념임은 확인, 내용은 미열람 |
| 공망 종류 | 삼명통회에는 순중공망 외 호환·절로·사대·오귀·극해공망 등이 있으나, **순중공망 외에는 이름만 남고 실제 감정에서 거의 안 씀** | 이원우(2020) 초록 확인 |
| 길흉 | 공망을 무조건 흉으로 보면 감정에 큰 오류. 비어 있어 채우려는 추구·갈망이 생긴다는 해석 | 이원우(2020) 초록 확인. 최상길·김만태(2016): 대체로 부정적이나 그 기운이 **왕상하면 오히려 전환 계기**, 직업·질병·업·택일 등에서 작용(초록 확인) |
| 위상 | 신살의 하나로, 격국·용신 중심 해석의 **보조** | 이원우(2020) 초록. 김만태(2025)는 공망·십악대패를 60갑자 구성(10과 12의 최소공배수) 과정에서 나온 신살로 설명(초록) |
| 자리별 해석 | 연해자평 「論妻妾」 "日坐空亡，難為妻妾", 「雜論口訣」 "時日空亡，難為妻子" | 연해자평 — 단정적 고전 문장이므로 서비스 문장에 그대로 쓰지 않음 |

## 해석에서 쓰이는 방식 — 신년운세 문장으로 이어지는 경로
1. 코드: 일주 순 공망 2지지 계산 → 세운 지지(未), 대운 지지, 원국 지지가 그 안에 있는지 표시.
2. 세운이 공망 자리면, 그 지지가 뜻하는 십신(예: 庚일간이면 未 = 정인)의 힘이 "덜 채워진 듯한" 상징으로 보조 서술.
3. 공망만으로 길흉을 말하지 않는다. 십신·합충보다 낮은 순위.

### 2027과 공망
| 사실 | 값 |
|---|---|
| 세운 未가 공망인 일주 | 甲申 乙酉 丙戌 丁亥 戊子 己丑 庚寅 辛卯 壬辰 癸巳 (甲申순) |
| 세운 간지 丁未가 속한 순 | 甲辰순 → 공망 寅·卯 (세운 기준 공망을 보는 학파용) |
| 未월(2027-07-07 소서 ~ 08-08 입추) | 같은 甲申순 일주에게 월운도 공망 자리 |

## 우리 적용 — 해석표 YAML 후보 (사용자 확인 전)
```yaml
gongmang:
  anchor: day_pillar          # 일주 기준. 대안: year_pillar, both
  branches_per_xun: 2         # 반순 1지지 세분법 사용 안 함
  check_targets: [liunian_branch, daewoon_branch, natal_branches]
  release_by_clash_combine: off   # 해공 판정 안 함(원문 미확인)
  text_weight: low
  forbidden: [배우자·자녀 운을 공망으로 단정]
```
- **검토 필요(2026-10-30, 논문 반영 메모 — 값은 바꾸지 않음)**: `branches_per_xun: 2`(순중공망만)와 `text_weight: low`는 이원우(2020)·최상길·김만태(2016) 초록과 같은 방향. 다만 두 논문 모두 "공망=무조건 흉"을 경계하므로, 문장 톤을 '비어 있음 → 채우려는 동기'처럼 양면으로 둘지 사용자 결정.

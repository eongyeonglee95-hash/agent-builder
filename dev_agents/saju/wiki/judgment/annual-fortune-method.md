# 신년운세 작성 절차

기준일: 2026-10-30 · 상태: 초안

## 요약 (5줄 이내)
- 신년운세는 **원국 요약 → 용신·희기 → 대운 맥락 → 세운(2027 丁未) 작용 → 월운 12개 → 영역별 매핑 → 좋음/주의 판정 → 문장** 순서로 만든다. 이 순서는 고전의 층위 원칙(원국 위에 대운, 대운 위에 세운)을 그대로 따른다.
- 각 단계를 **코드가 결정할 것 / 해석표(YAML)에서 올 것 / LLM이 쓸 것**으로 나눴다. LLM은 계산하지 않고, 판정도 하지 않으며, 주어진 사실과 문구 후보 안에서 문장만 쓴다.
- 판정에서 가장 흔들리는 고리는 **용신**이다. 사례 A는 용신을 水로 보면 2027년 세운 점수가 -1.5(주의), 土로 보면 +1.5(도움)로 정반대가 된다. 그래서 확신도와 대안을 함께 넘기고, 확신도가 낮으면 톤을 약하게 한다.
- 좋음/주의 판정 기준은 "올해 글자가 용신 쪽인가(오행 생극) + 원국과 합인가 충인가 + 대운이 받쳐 주나"를 결정적 점수로 계산한다. 수치 가중은 고전에 없으므로 **우리 설계값**이며 골든 사례로 조정한다.
- 사례 A(1990-05-15 10:30 서울 남, 庚午 辛巳 庚辰 辛巳)로 끝까지 시연했다. 모든 계산 값은 scratchpad 스크립트 실행 결과다.

### 2. 영역 매핑 규칙 후보 (단계 8)
십신이 사람·주제와 연결되는 육친·성정 분류는 고전 공통 지식(『연해자평』 六親總篇·論正財·正官論 등 절 구성)이고, 아래 "현대 영역" 칸은 우리 상품용 묶음이다.

| 십신 | 고전 육친(남/여) | 현대 영역(우리 묶음) |
|---|---|---|
| 정관·편관 | 남: 자녀 / 여: 남편 | **일**(직장·책임·평가·규칙), 여성은 **관계**(배우자)도 |
| 정재·편재 | 남: 아내·부친 / 여: 부친 | **재물**(수입·지출·관리), 남성은 **관계**(배우자)도 |
| 식신·상관 | 남: (손아랫사람) / 여: 자녀 | **일**(표현·성과물·기술), 여성은 자녀 |
| 정인·편인 | 모친 | **배움·문서**(자격·계약·학습), 휴식 |
| 비견·겁재 | 형제·동료 | **관계**(동료·경쟁), **재물**(나눔·지출) |
| 일지(배우자 자리)와의 합충 | — | **관계** |
| 조후 치우침, 일간을 극하는 기운 과다, 충 다수 | — | **컨디션**(건강은 단정 금지, '리듬·휴식' 수준) |

### 3. 좋음/주의 판정 공식 후보 (단계 9)
```
element_tag: 용 +2, 희 +1, 한 0, 구 −1, 기 −2      # 용신 오행 기준
pillar_score = 0.5·tag(천간) + 0.5·tag(지지)        # 세운: "歲看干"을 반영하려면 천간 0.6
relation_adj:
  원국/일지와 합(육합·방합·삼합) 성립: 합이 만드는 오행의 tag × 0.5 가산
  일지·월지 충: −0.5 (사건성 플래그 'change'를 같이 켬; 좋고 나쁨은 tag가 결정)
  형·파·해: −0.25
dayun_context: 대운 pillar_score를 0.3 가중으로 더함 (교운 전후는 각각 따로 계산)
confidence 반영: confidence=low → 최종 점수 × 0.5, mid → × 0.75
tone: ≥ +0.75 좋음 / ≤ −0.75 주의 / 그 사이 보통
```
- 모든 수치는 **근거 없는 설계 초기값**이다. 고전은 "합이면 누가 가까운지, 충이면 누가 이기는지"를 보라고 할 뿐 수치를 주지 않는다(『적천수』 「歲運論」).
- 점수는 내부 정렬·톤 결정용으로만 쓰고 화면에 숫자로 노출하지 않는 것을 권한다(바넘·과신 위험, `papers/validity-skepticism.md`).
- 왜 LLM에 판정을 맡기지 않나: 같은 명조를 생성형 AI 4종에 줬더니 신강신약·용신·종격 판단이 모델마다 다르고 십신·지장간 착오가 나왔다는 KCI 논문이 있다(이영은 2026). 용신 선택은 형식화가 어려운 암묵지 영역이라는 분석(전세연 2026)과 합치면, "판정은 코드 규칙 + 확신도, LLM은 문장만"이 가장 방어 가능한 설계다.

### 6단계 세운 丁未 작용 (코드)

# 격국

기준일: 2026-10-30 · 상태: 초안

## 요약 (5줄 이내)
- 격국(格局)은 사주의 "틀·유형 이름"이다. 『자평진전』은 **태어난 달의 지지(월령)** 에서 격을 세우고, 그 격이 잘 짜였는지(성격)·깨졌는지(파격)로 사람의 그릇을 본다.
- 정격(正格, 내격)은 현대 관행에서 월령의 십신으로 이름 붙인 8격 — 정관·편관(칠살)·정재·편재·정인·편인·식신·상관 — 에 건록·양인(월겁)을 더해 말한다. 『자평진전』 원문은 정·편재를 한 재격, 정·편인을 한 인수격으로 묶는다(원문 대조).
- 외격(外格)은 일간이 한쪽 기운을 따르는 종격·화격, 한 오행이 판을 차지하는 전왕격(곡직·염상·가색·종혁·윤하) 등이다. 판정 경계가 가장 애매한 영역이다.
- "월령 → 투출 확인 → 격 이름"까지는 코드로 결정할 수 있다. 성격·파격 판정은 규칙 후보가 있지만 해석가 재량이 크다.
- 현대 실무가 중에는 격국을 건너뛰고 바로 용신으로 가는 쪽(박재완 등)과 월령 격국을 먼저 세우는 쪽(위천리·아베 타이잔)이 있다는 학술 정리가 있다(최정혜 2025). 실무 비중을 수치로 보여 주는 자료는 찾지 못했다.

## 개념 — 정의, 표, 계산 규칙

### 1. 격을 세우는 순서 (『자평진전』 「論用神」「論用神變化」 기반)
- 「論用神」 첫 문장: 사주의 용신은 오로지 월령에서 구하고("八字用神，專求月令"), 일간과 월지를 짝지어 생극이 달라지는 데서 격국이 나뉜다(공개 원문 『耕寸集』본으로 대조, 출처 아래).
  - 자평진전에서 "용신"은 대개 **격의 중심 글자(격용신)** 를 뜻한다. 억부론의 "필요한 글자(용신)"와 같은 말이지만 뜻이 다르다. 이 혼동이 현대 한국 명리 논쟁의 큰 원인이다(`useful-god.md`).
- 같은 절: 재·관·인·식은 "좋은 용신이라 순하게 쓰고(順用)", **살·상관·양인·월겁(煞傷刃劫)** 은 "좋지 않은 용신이라 거슬러 쓴다(逆用)"고 한다. 지난 초안의 "효신(편인)을 역용" 표기는 원문과 달라 고쳤다(2026-10-30 대조).
  - 편인은 따로 역용 목록에 없다. 「論印綬」는 인수가 일간을 낳는 것을 좋아하며 "正偏同為美格"이라 하고, 재와 인은 정·편을 나누지 않고 한 격으로 논한다고 적는다. 「論用神」도 월령 편인에 식신이 투출하면 효신탈식으로 보지 말고 설기의 빼어남으로 보라고 한다.
  - 「論四凶神能成格」은 살·상관·효(梟)·양인을 "四凶神"으로 묶지만, 이는 순역 분류가 아니라 "쓰기에 따라 격을 이룬다"는 절이다.
- 같은 절: 월령이 일간과 같은 오행(건록·월겁)이면 그 자체를 용신으로 쓰지 못하고, 사주의 재·관·살·식 중 투간·회지한 것을 따로 골라 쓴다. 「論建祿月劫」도 건록과 월겁을 한 격으로 보고 "별도로 재관살식을 취해 용신으로 삼는다"는 취지로 적는다.
- 「論用神變化」: 월지에 숨은 글자가 여럿이라 용신이 바뀔 수 있다. 寅월에 甲(본기)이 투출하지 않고 丙이 투출하면 丙이 주인 노릇을 한다는 비유를 든다.

### 2. 결정적 규칙 후보 (코드로 옮길 수 있는 부분)
```
1. 월지의 지장간 [본기, 중기, 여기]를 구한다.
2. 연·월·시 천간(일간 제외)에 지장간 중 투출한 글자가 있는지 본다.
3. 본기가 투출했거나, 아무것도 투출하지 않았으면 → 본기의 십신으로 격 이름.
4. 본기는 투출하지 않고 다른 지장간이 투출했으면 → 투출한 글자의 십신으로 격 이름(「論用神變化」).
5. 그 글자가 비견·겁재(일간과 같은 오행)면 → 격으로 쓰지 않고 건록격(월지가 일간의 록)·양인격(월지가 양간의 양인)으로 따로 이름 붙이거나, 다른 투출 글자를 본다.
6. 子午卯酉(지장간이 한 글자로 보는 학파 기준)는 본기 하나로 정한다.
```
- 학파 선택이 필요한 지점:
  - 지장간 구성(午 = 丁己 / 丙己丁, 子·卯·酉의 여기 포함 여부 등). lunar-python은 午 = [丁, 己].
  - 투출 글자가 둘 이상일 때 우선순위(본기 > 중기 > 여기로 할지, 월간 투출 > 다른 자리로 할지). 최원호·김기승(2023)은 이런 **겸격(兼格)에서 최종 격을 고르는 방법이 원전에 없다**고 지적하고, 월지와 합하는 지지·투출 천간의 강도·일간 강약 세 요인으로 규칙을 정리했으나 스스로 주관적 규칙이라고 인정했다.
  - 辰戌丑未(사고지, 잡기) 월: 「論雜氣如何取用」(원문 대조). 사고지는 여러 글자를 품어 "잡기"라 하며, **천간에 투출하거나(透干) 지지가 회국하는(會支) 글자 중 맑은 것을 쓴다**("透干會支，取其清者用之")고 한다.
    - 하나가 투출하면 그것을, 둘이 투출하면 함께(兼用), 투출하고 회국도 하면 둘을 함께(并用) 쓴다. 예: 甲일 辰월에 戊 투출 → 편재, 癸 투출 → 정인, 乙 투출 → 월겁, 申·子와 회국 → 수(인).
    - 함께 쓰는 글자끼리 서로 살리면(順而相成) 유정(길), 서로 해치면(逆而相背) 무정(불길). 유정이 무정으로 바뀌거나 그 반대인 경우도 예를 든다 → 결정적 규칙은 "투출·회국 후보 목록"까지, 유정·무정은 플래그.
    - 「論墓庫刑沖之說」: "辰戌丑未는 형충해야 열린다(不沖不發)"는 속설을 자평의 법이 아니라고 반박한다. 투간·회지가 있으면 충을 기다릴 필요가 없다는 입장.

### 3. 정격 8격 + 2 (표)

| 격 | 월령(또는 투출) 십신 | 순용/역용(자평진전 「論用神」) | 성격이 되는 대표 조건(요지) |
|---|---|---|---|
| 정관격 | 정관 | 순용 | 재(財)가 관을 돕고 인(印)이 관을 보호, 상관·칠살 혼잡이 없을 때 |
| 편관(칠살)격 | 편관 | 역용 | 일간이 강하고 살이 제복될 때(「論用神成敗救應」). 「論偏官」은 식신 제살을 으뜸으로, 인으로 살을 화하는 것(七煞用印)은 살·인이 유정할 때 귀격으로 든다 |
| 재격(정·편 한 격) | 재성 | 순용 | 재가 관을 낳거나 식신이 재를 낳고 일간이 강할 때. 비겁이 무겁거나 칠살이 투출하면 패 |
| 인수격(정·편 한 격) | 정인·편인 | 순용 | 인이 가벼울 때 관살이 인을 낳고, 재가 인을 깨지 않을 때 |
| (편인격) | 편인 | 원문에 별도 격 없음 → 인수격에 포함 | 현대 10격 구분. 『자평진전』식으로 쓰면 인수격 조건을 따른다 |
| 식신격 | 식신 | 순용 | 식신이 재를 낳거나 살을 제어할 때, 편인이 식신을 치지 않을 때 |
| 상관격 | 상관 | 역용 | 상관이 재를 낳거나(상관생재) 인으로 상관을 다스릴 때(상관패인) |
| 건록격·월겁격(한 격) | 월지가 일간의 록 또는 겁재 | 역용(월겁) | 녹·겁 자체는 용신이 못 됨. 관 투출에 재·인이 따르거나, 재를 쓰면 식상으로 겁을 화함 |
| 양인격 | 월지가 양간의 양인 | 역용 | 관살로 양인을 제어할 때 |

- (2026-10-30) 위 표는 『자평진전』 공개 원문(『耕寸集』본)과 대조해 고쳤다. 더 자세한 원문 조건은 아래 3-1이 우선이다. 『연해자평』의 「正官論」「論七殺」 등 각 격론 대조는 아직 하지 않았다.
- **『자평진전』은 정인·편인을 "인수(印綬)" 한 격으로, 정재·편재를 "재(財)" 한 격으로 다룬다**(「論印綬」 "正偏同為美格", 「論財」). 표의 "편인격(효신)·역용" 행은 원문에 없는 구분이다. 편인을 따로 격으로 세우는 것은 현대 관행(학파 선택)으로 표시해야 한다.

#### 3-1. 「論用神成敗救應」 원문 요지 (원문 대조)
| 격 | 성(成) — 원문 조건 요지 | 패(敗) — 원문 조건 요지 |
|---|---|---|
| 정관 | 관이 재·인을 만나고 형충파해가 없음 | 관이 상관의 극이나 형충을 만남 |
| 재 | 재가 왕해 관을 낳음 / 식신이 재를 낳고 일간이 강하며 비견을 낌 / 인이 투출했으나 자리가 떨어져 서로 다치지 않음 | 재가 가볍고 비겁이 무거움 / 재격에 칠살 투출 |
| 인수 | 인이 가볍고 살을 만남 / 관인쌍전 / 일간·인 둘 다 왕하고 식상으로 설기 / 인이 많은데 재가 투출하되 뿌리가 가벼움 | 인이 가벼운데 재를 만남 / 일간 강·인 무거운데 살 투출 |
| 식신 | 식신이 재를 낳음 / 식신이 살을 띠고 재가 없음 / 식신을 버리고 살을 따르며 인 투출 | 식신이 효신(편인)을 만남 / 재를 낳는데 살이 드러남 |
| 칠살 | 일간이 강하고 살이 제복(制)됨 | 살이 재를 만나고 제복이 없음 |
| 상관 | 상관생재 / 상관패인(상관 왕·인 유근) / 상관 왕·일간 약에 살·인 투출 / 상관이 살을 띠고 재 없음 | 금수상관이 아닌데 관을 봄 / 생재하는데 살을 띰 / 패인인데 상관 가볍고 일간 왕 |
| 양인 | 관·살이 투출하고 재·인이 드러나며 상관이 없음 | 관·살이 없음 |
| 건록·월겁 | 관 투출에 재·인을 만남 등 | 재·관이 없고 살·인만 투출 |

- 같은 절: "성 속의 패는 반드시 기신을 띤 것(帶忌)", "패 속의 성은 오로지 구응(救應)에 달렸다". 예: 관이 상관을 만났는데 인이 투출해 풀어 줌, 살이 섞였는데 합으로 맑힘, 형충을 회합으로 풂.
- 절 끝: 사주의 묘용은 모두 성패·구응에 있고 그 경중이 매우 활변(活變)하다고 한다 → **원문 스스로 고정 규칙이 아니라고 말한다.** 우리 "성패는 플래그만" 설계와 맞다.
- 「論相神緊要」: 격을 이루게 하는 한 글자를 상신(相神)이라 하고, "용신을 다치는 것보다 상신을 다치는 것이 더 심하다"(傷相甚於傷用)고 한다. 상신이 다치면 귀격이 바로 깨진다.
- 「論用神格局高低」: 같은 격이라도 고저는 유정·무정, 유력·무력에 달렸다고 한다(정량 기준 없음).
- 「論用神配氣候得失」: 월령 용신을 주로 하되 기후(조후)를 배합해 참고하라고 한다. 예: 겨울 木이 관인쌍전이어도 물이 얼어 귀하기 어렵다. → 자평진전도 조후를 보조로 쓴다.

### 4. 성격(成格)·파격(破格)·구응(救應)
- 개념: 격을 돕는 글자(相神)가 있고 격을 해치는 글자가 없으면 성격, 해치는 글자가 있으면 파격, 해치는 글자를 다시 막아 주는 글자가 있으면 "구응(救應)으로 다시 이룬다".
- 예(정관격): 상관이 관을 치면 파격, 인성이 상관을 막으면 구응.
- 김형순(2015)은 이를 1차 성패(순용·역용) 뒤 2차로 다른 글자가 결과를 뒤집는 구조로 정리한다: 성 속의 패를 만드는 글자 = 대기(帶忌), 패 속의 성을 만드는 글자 = 구응. 상신은 이 변화 전체를 가리킨다고 본다.
- 코드화 가능성: "어떤 십신이 원국 어디에 있다"는 결정적이다. 그러나 **힘의 크기(투출·통근·거리·합으로 묶임)** 를 비교해 "막았다/못 막았다"를 정하는 부분은 해석가 판단이 크다. → 규칙은 "후보 플래그"까지만 만들고 최종 판정은 하지 않는 것을 권한다.

### 5. 외격
| 유형 | 정의 요지 | 판정 난도 |
|---|---|---|
| 종격(從格): 종재·종살·종아(식상)·종강·종왕 | 일간이 뿌리가 거의 없어 강한 세력을 따름(또는 일간 쪽이 압도적이라 그 세력을 따름) | **높음**. 『적천수』 「從化論」은 "진종(真從)"과 "가종(假從)"을 나눈다 — 가종은 "日主弱矣，財官強矣，不能不從，中有所助者，便假"(약하지만 조금 돕는 글자가 있으면 가짜 종) 취지 |
| 화격(化格) | 일간이 옆 천간과 합해 다른 오행으로 변함(甲己→土 등) | 높음. 「從化論－真」 주석은 "甲일간이 사계(辰戌丑未)월에 己와 합하고 방해 글자가 없어야 진화(真化)"라는 식으로 조건을 단다 |
| 전왕격(곡직·염상·가색·종혁·윤하) | 한 오행이 방합·삼합으로 판을 차지 | 중간. 합국 성립은 결정적이지만 "섞인 글자가 얼마나 있으면 깨지나"는 재량 |
| 잡격(비천록마·도충 등) | 특정 글자 조합 | 학파·문헌마다 목록이 다름. 서비스 범위 밖 권장 |

- **「論星辰無關格局」**: 격국은 오로지 월령을 사주에 배합해 정하고, 신살(星辰)의 좋고 나쁨은 생극에 쓰일 수 없으므로 성패를 좌우하지 못한다. 격이 이루어지면 고진·팔살이 가득해도 귀함을 덜지 못하고, 격이 깨지면 천덕·귀인이 가득해도 공이 없다는 취지. 옛 책의 "祿貴"는 녹당·귀인 신살이 아니라 정관을 가리키는 경우가 많다고도 적는다.

## 해석에서 쓰이는 방식 — 신년운세 문장으로 이어지는 경로

신년운세에서 격국은 "이 사람의 기본 무대(일의 방식)"를 정하는 배경으로 쓰고, 세운이 **격을 돕는 글자(相神)를 가져오는지 / 격을 깨는 글자를 가져오는지**를 본다.

**사례 A(庚午 辛巳 庚辰 辛巳)에 결정적 규칙 적용** (lunar-python 지장간, scratchpad `judg_case.py`):
1. 월지 巳의 지장간 = [丙(본기), 庚(중기), 戊(여기)].
2. 천간(연 庚, 월 辛, 시 辛)에 투출: 庚(중기)만 투출 → 庚은 일간과 같은 金(비견)이라 격으로 쓰지 않는다(규칙 5).
3. 본기 丙 = 일간 庚 기준 **편관** → **편관(칠살)격** 후보.
4. 성패 플래그(후보): 연지 午 = 정관 → 관살혼잡 플래그. 살을 제어할 식신(壬)은 원국에 없음. 살을 화할 인성은 일지 辰(편인 戊)·巳 여기 戊. → "인성으로 살을 화하는 구조(살인상생) 후보, 식신 제살 없음".
5. 2027 丁未: 丁 = 정관이 천간에 들어와 관살(火)이 더 강해지고, 未 = 정인(己)이 함께 들어온다. 격국 관점의 사실 문장: "살격에 관이 더해지고 인성이 함께 들어오는 해". 이를 좋다/나쁘다로 단정하는 것은 학파 선택(살을 인으로 화하는 것을 성격으로 볼지, 관살혼잡 심화를 파격으로 볼지)에 달려 있다.

  reveal_priority: [main, middle, residual]   # 투출 다수일 때 본기>중기>여기

**검토 필요 (사용자 결정 전, 값은 바꾸지 않음)**
- `sachang_months_rule`: 「論雜氣如何取用」 원문으로 후보 규칙을 세울 수 있다 — "투간·회지 글자를 모두 후보로, 하나면 그 글자, 여럿이면 겸용 표시, 유정/무정은 플래그". `unresolved` → 이 규칙으로 바꿀지 결정 필요.
- 격 이름 체계: 자평진전식이면 정·편인 → "인수격", 정·편재 → "재격"으로 묶는다. 현재 `gyeok_name: deterministic`이 십신 이름(편인격·편재격)을 그대로 낼 경우 원문과 어긋난다. 표시 이름을 원문식으로 할지, 현대식(10격)으로 하고 "현대 구분"이라 밝힐지 결정 필요.
- 순역 분류: 역용 = 살·상관·양인·월겁(원문). 편인을 역용으로 다루는 코드·표가 있으면 고쳐야 한다.

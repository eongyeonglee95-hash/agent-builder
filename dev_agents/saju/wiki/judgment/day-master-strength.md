# 신강·신약

기준일: 2026-10-30 · 상태: 초안

## 요약 (5줄 이내)
- 신강·신약은 "나(일간)를 돕는 기운이 많은가, 나를 빼는·누르는 기운이 많은가"를 재는 판단이다. 용신(억부)을 고르는 첫 단계다.
- 전통 기준은 **득령(태어난 달의 도움) · 득지(일지의 도움) · 득세(다른 글자의 도움)** 세 가지다.
- 고전은 "왕하면 덜고 쇠하면 돕는다"는 원칙만 주고 **점수 가중치는 주지 않는다**. 점수화는 현대 저자·연구자의 선택이고(예: 왕상휴수사 5~1점, 임계 ±8~±12), 국내 박사논문도 "합의가 없어 현장이 혼란"하다고 쓴다.
- 사례 A(庚午 辛巳 庚辰 辛巳)는 득령 ✕·득지 ○·득세 ○인데, 우리가 계산한 세 점수 방식에서 돕는 기운 비율이 0.50 ~ 0.64로 **경계 근처**에 걸린다. 실제 해석가끼리도 갈릴 만한 사주다.
- 그래서 코드는 "점수 + 구간(신강·중화·신약) + 애매 플래그"까지 결정하고, 애매 구간에서는 조후·격국 판단과 함께 보고 문장 강도를 낮춘다.

## 개념 — 정의, 표, 계산 규칙

### 1. 돕는 쪽과 빼는 쪽
| 일간 기준 | 십신 | 작용 |
|---|---|---|
| 같은 오행 | 비견·겁재(비겁) | 돕는다 |
| 나를 낳는 오행 | 정인·편인(인성) | 돕는다 |
| 내가 낳는 오행 | 식신·상관(식상) | 힘을 뺀다(설기) |
| 내가 이기는 오행 | 정재·편재(재성) | 힘을 쓰게 한다(소모) |
| 나를 이기는 오행 | 정관·편관(관살) | 누른다(극) |

### 2. 득령·득지·득세
| 기준 | 정의 | 사례 A |
|---|---|---|
| 득령(得令) | 월지(특히 본기)가 일간을 돕는가. 월지 = 계절 = 가장 큰 힘이라는 것이 고전 공통(『적천수』 「月令論」은 월령을 집에, 그 안의 당령 신을 집의 방향에 비유) | 巳 본기 丙 = 편관 → **실령(✕)**. 단 巳 중기 庚 = 비견, 庚의 12운성 장생이라 "완전한 실령은 아니다"라는 반론 여지 |
| 득지(得地) | 일지가 일간을 돕는가(통근) | 辰 본기 戊 = 편인 → **득지(○)**. 辰은 젖은 흙이라 金을 낳는다고 보는 것이 일반적 |
| 득세(得勢) | 나머지 글자 다수가 돕는가 | 천간 庚·辛·辛(비겁 3), 지지 午·巳(火 2) → **득세(○)** |
| 흔한 요약 규칙 | 셋 중 둘 이상 → 신강 | **신강** 쪽. 그러나 아래 점수 방식에 따라 경계 |

- "셋 중 둘" 규칙은 현대 한국 입문 강의에서 흔히 들리는 간이법이지만, 이를 명시한 고전 원문은 이번 조사 범위에서 찾지 못했다(**미확인**).

### 3. 점수화 방식 — 같은 원국, 다른 결과
고전에는 수치가 없으므로 아래 세 방식은 **비교를 위한 예시 정의**다(우리가 정의, scratchpad `calc/strength.py`, 2026-10-30 실행). 학술·현대 저자의 가중치는 "학파·문헌별 차이"에 출처와 함께 따로 적는다.

| 방식 | 정의 | 사례 A: 돕는 점수 / 전체 | 비율 |
|---|---|---|---|
| ① 동등 | 일간 뺀 7글자, 지지는 본기 오행, 각 1점 | 4 / 7 | 0.571 |
| ② 위치 가중 | 월지 3 · 일지 2 · 나머지 지지 1 · 천간 1 | 5 / 10 | **0.500** |
| ③ 지장간 분할 + 월지 2배 | 지장간을 본기 0.6·중기 0.3·여기 0.1(두 글자면 0.7·0.3)로 나눔, 월지는 2배 | 5.1 / 8.0 | 0.637 |

- ②에서 정확히 0.5가 나온다. 이 경계에서 "신강/신약"을 단정하면 문장 전체가 뒤집힌다(용신이 水 ↔ 土로 바뀜, `useful-god.md`).
- ③처럼 지장간을 넣으면 巳 속 庚·戊, 辰 속 戊 때문에 돕는 쪽이 올라간다. **지장간을 넣느냐가 결과를 가장 크게 흔든다.**
- 그 밖에 결과를 흔드는 선택: 합으로 오행이 바뀌는 것(巳午未 방합 성립 시 火 가중)을 반영하느냐, 12운성(장생·건록 = 뿌리)을 가점하느냐, 천간 투출 글자의 통근을 가점하느냐.

### 4. 결정적 판정 규칙 후보
```
score = 돕는 가중합 / 전체 가중합         # 방식은 YAML로 선택
band:
  score >= 0.60 → 신강
  0.45 <= score < 0.60 → 중화(애매)        # 임계값은 골든 사례로 조정 전 임시값
  score < 0.45 → 신약
extreme:
  돕는 글자 비율 >= 0.85 또는 <= 0.15 → 종격 후보 플래그(structures-gyeokguk.md 외격)
ambiguity:
  여러 방식 결과가 서로 다른 band → ambiguous = true
```
- 애매 플래그가 켜지면: 억부 용신 단독 판정을 하지 않고, 조후(`climate-johu.md`)와 격국(`structures-gyeokguk.md`) 결과를 함께 facts로 넘긴다. LLM 문장은 "타고난 기운이 한쪽으로 크게 치우치지 않은 편" 같은 중립 톤만 허용.

## 학파·문헌별 차이

| 문헌·관점 | 강약을 보는 법 |
|---|---|
| 『적천수』 「衰旺論」 | 쇠왕의 참된 기미를 알면 명리의 절반을 안다. 주석: 왕하면 설·상하고 쇠하면 돕는 것이 자평의 이치지만, 왕 속에 쇠가 있고 쇠 속에 왕이 있으며, 극에 달한 왕은 덜면 안 되고 극에 달한 쇠는 보태면 안 된다(→ 종격 논리) |
| 『적천수』 「中和論」 | 중화가 정리(正理)이고 가장 귀하다. 다만 주석은 신약에 재관이 왕해도 부귀할 수 있다며 중화 = 유일한 좋은 상태가 아님을 인정 |
| 『적천수』 「體用論」 | 체용은 한 가지로 논할 수 없고, 돕고 누르는 것이 마땅함을 얻는 것이 요점("扶之抑之得其宜") — 억부론의 근거 문장으로 흔히 인용 |
| 『적천수』 「月令論」 | 월령 = 집, 당령한 지장간 = 집의 방향 → 월지 가중이 가장 크다는 근거 |
| 『연해자평』 「論性情」 | 일간이 약하면 물러서고, 강하면 고집스럽다는 성정론 — 강약을 성격 서술로 연결한 고전 예 |
| 『궁통보감』 | 강약보다 계절(조후)을 먼저 본다. 강약은 칸별 조건 문장으로 섞여 나온다 |
| 이나현(2024, 경기대 박사) | 고전 3종·현대 한국서 3종(사주정설·사주첩경·명리요강)을 비교해 기준을 다시 세움: 천간 전체 기운, 지장간 통근·투간, **통근 위치 강도 월지 > 시지 > 일지 > 연지**. 수치 가중치는 없음. 출발점이 "신강신약론에 합의가 없어 현장이 혼란"이라는 문제의식(초록·목차) |
| 이영숙(2026, 동방문화대학원대 박사) | 왕상휴수사에 **5·4·3·2·1점**, 강약 임계치 세 기준(**±8, ±10, ±12**), 득령은 별도 변수. 문헌 명조 2,050건으로 점수 체계를 검증. 위치별 가중치·합산식은 초록에 없음(본문 미열람). 저자도 임계치 타당성은 추가 검토가 필요하다고 밝힘 |
| 최정혜(2023, 동방문화대학원대 박사) — 아베 타이잔 체계 | 득시(월령·왕상휴수사), 생부극설의 다소, 12운성(득세) 세 기준. 12운성 상수로 강약을 수치화한다고 소개(상수값은 초록에 없음) |
| 윤상흠(2022, 원광대 박사) | 억부론이 중화를 "힘의 수치 균형"으로만 보고 득령·득지·득세를 수치화하는 데서 오류가 생긴다고 **비판**, 시중(時中)의 상대적 중화를 대안으로 제시 |
| 전세연(2026, 『동양문화융합』) | 명리 지식 형식화 4분류에서 오행 분석은 "완전 형식화" 가능, 용신 선택은 "형식화 불가(암묵지)"로 분류. 신강신약 점수화 위치는 초록에 없음 |
| 許毓芳(2009, 국립대만대 석사) | 신강 판단 기준이 복잡·주관적이라 분석 변수에서 일부러 뺐다고 본문에 명시 |
| 권영민(2022, 『문화와융합』 KCI) | 신약을 심리학의 고민감성(HSP)과 비교하는 해석. 판정 방법은 없음 |
| 현대 앱·라이브러리 | 기둥 가중치(예: 월 > 일 > 시 > 연)를 쓰는 오픈소스가 있다는 단서가 있으나 학술 출처 아님(인용 안 함) |

## 해석에서 쓰이는 방식 — 신년운세 문장으로 이어지는 경로
1. 강약 band → 억부 용신 방향(신강이면 식상·재·관, 신약이면 인성·비겁).
2. 세운·월운 글자가 그 방향과 같은지 → 희신/기신 판정(`useful-god.md`).
3. 강약 자체는 성향 문장에도 쓰인다(예: "스스로 밀고 나가는 힘이 큰 편" / "주변 도움을 받을 때 힘이 나는 편"). 단정 대신 "고전은 이런 구성을 ~로 본다".

사례 A: band는 방식에 따라 중화~신강. 애매 플래그 ON → 2027 해석에서 "丁未가 좋다/나쁘다" 단정 대신 주제(정관 = 책임, 정인 = 배움·문서) 중심으로 쓰고, 용신 학파별 결과는 facts에 둘 다 남긴다.

## 우리 적용 — 해석표 YAML 후보 (사용자 확인 전)

```yaml
day_master_strength:
  method: weighted_hidden_stems        # ③. 대안: equal(①), position(②)
  weights:
    stems: 1.0
    branch_position: { year: 1.0, month: 2.0, day: 1.0, hour: 1.0 }
    hidden_ratio: { 3: [0.6, 0.3, 0.1], 2: [0.7, 0.3], 1: [1.0] }   # 근거 미확정. 학술 가중치로 교체 후보
  combos_change_element: false         # 방합·삼합으로 오행 변환 반영 안 함(1차)
  twelve_stage_bonus: false
  bands: { strong: 0.60, weak: 0.45 }  # 임시. 골든 사례(전문가 감수 20~30건)로 조정
  extreme_flag: { high: 0.85, low: 0.15 }
  ambiguity: run_all_methods_and_compare
  output_facts: [score, band, ambiguous, deukryeong, deukji, deukse]
```

## 미확인 · 열린 질문
- "셋 중 둘이면 신강" 간이 규칙의 원 출처.
- 학술·현대 저자 가중치 중 무엇을 기본값으로 삼을지 — 골든 사례 감수 없이는 정할 수 없다. 이영숙(2026) 본문(위치별 가중치·합산식), 최정혜(2023) 본문(12운성 상수)을 열람하면 근거 있는 대안 가중치를 얻을 수 있다(후속).
- 이나현(2024)의 통근 위치 순서(월지 > 시지 > 일지 > 연지)는 우리 예시 방식 ②(일지 2 > 시지 1)와 다르다. 위치 가중을 쓸 거면 이 순서를 반영할지 결정 필요.
- 巳월 庚金처럼 "본기는 극하지만 중기가 비견·장생"인 달을 득령으로 볼지 — 학파 선택.
- 합·국에 의한 오행 변환을 강약 점수에 넣을지.

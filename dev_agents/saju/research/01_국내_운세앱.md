**2) 결과 화면 구성**

  - 예: "2027 새해 운명의 시나리오 2,000", "2027년 당신의 흐름을 바꿀 7가지 운세 코드 800", "2027 대예언: 그대가 맞이할 빛과 그림자 1,000", "11월 사주 재물운"(조회 40,749) 등

- 신년운세(케이뱅크 판, 정가 22,000원): "신년 총운, 5개 분야(재물·건강 등), 1~12월 월별 운세" (블록미디어)
- 사주를 캐릭터로 표현해 "한자를 몰라도 이해하기 쉽다" (GQ 2022)

1. **계산이 맞는 것**이 바닥이다. 십신·대운·야자시가 틀리면 아는 사용자는 즉시 떠나고 리뷰에 쓴다. 진태양시(연월재), 출생지 시각 보정(원광), "±1분 정밀"(도사), 30분 어긋난 시 경계(네이버)처럼 **보정 방식을 겉으로 말하는 것**이 신뢰 표시로 쓰인다.
2. **같은 사람에게는 늘 같은 답**: 다시 열어도, 다른 메뉴에서도, 대화 중에도 같아야 한다. 리뷰 불신의 상당 부분이 "바뀜·모순"이다.
3. **다른 사람과는 달라야 한다**: 생년월일이 다른데 같은 문장이 나오면 끝이다. 개인 명식에서 나온 구체 요소(일간·특정 월·특정 나이)를 문장에 넣어야 한다.
4. **구체적 시기**: "몇 월", "상반기/하반기", "힘 실을 달/쉬어 갈 달". 맞았다는 리뷰의 대부분이 시기 이야기다.
5. **내 상황 연결**: 사주핑의 기억, 연월재의 "궁금한 거 하나 적어 줘" → 마지막에 답. 질문 하나를 받아 리포트 끝에 묶어 주면 맞춤 느낌이 크게 오른다.
6. **여러 체계의 교차 확인**: 타이트사주·포스텔러 모두 사주+별자리+자미두수를 같이 쓰고, 사용자가 이를 차별점으로 언급한다. 우리 5개 렌즈 구조와 같은 방향.
7. **쉬운 말 + 근거 한 줄**: 한자 용어는 일상어로 풀되, 원하면 명식(간지·오행)을 볼 수 있게. 만세력 애호가와 일반 사용자를 같이 잡는 방식.
8. **캐릭터 화자**: 포스텔러 '릴리', 헬로우봇, 청월당·연월재 웹툰 캐릭터. 말투가 일정한 화자가 있으면 몰입이 생긴다. 다만 대화형은 LLM이 말을 바꾸는 위험이 커진다.

### 4-2. 우리가 따라 할 것
- **입력 한 화면**: 성별 · 양력/음력(평)/음력(윤) · 생년월일 · 태어난 시(12지시 + 모름) — 네이버 방식. 여기에 출생지(시 보정용, 선택)와 이름(성명학용)을 더함. 시각 모름은 기본 허용하되 "시주 없이 본 결과"임을 결과에 표시하고, **나중에 시각을 추가·수정할 수 있게** (포스텔러 불만 반영)
- **야자시/조자시 선택, 서머타임(1948~1988 해당 연도) 자동 보정**, 보정 내역을 결과 하단에 공개
- **결과 고정**: 같은 입력이면 같은 리포트. LLM 문장은 한 번 만들면 저장해 다시 보여 주고, 다시 생성하지 않음 (점신·사주핑 "바뀜" 불만 방지)
- **렌즈 간 모순 검사**: 사주 연운과 자미두수 유년이 다른 말을 하면 숨기지 말고 "두 렌즈가 다르게 본다"고 적거나, 코드에서 우선순위 규칙을 정함 (점신 메뉴간 모순 불만 방지)
- **월별 운세는 '힘 실을 달 / 쉬어 갈 달' 구분 + 짧은 이유** — 점수만 주지 않기 (55점 반복 불만)
- **첫 화면 순서 제안**: 올해 한 줄 요약 → 내 명식 핵심(일간·오행 쉬운 말) → 12개월 흐름 표 → 분야별(재물·일·사랑·사람·건강) → 렌즈별 근거 펼쳐 보기 → 마무리 조언
- **공유**: 카톡 공유(다음·한화생명·케이뱅크 모두 사용). 공유 카드에는 개인 명식이 아니라 한 줄 요약만
- **질문 하나 받기** (연월재 방식): 입력 단계에서 "올해 가장 궁금한 것 하나"를 받아 마지막 장에서 답함

### 4-3. 피할 것
- 공포 서사·가짜 긴박감: 청월당 신년 랜딩(생활고·배신·파혼 연대기 → "적중률 100%" → 카운트다운)
- 근거 없는 수치: "적중률 100%", 모든 상품 ★5.0, "상위 1%만"
- 나쁜 운을 상품으로 연결: 살풀이·부적·액막이 판매 (점신·포스텔러). 보험사가 하면 "불안 마케팅"으로 읽힘
- 단정·인신공격형 문장: "실망", "재수없다", "판이 뒤집히는 날"
- 그때그때 생성하는 대화형 풀이: 헬로우봇의 결혼 연도 말 바꾸기, 사주핑 품질 저하. 타로 대화 입구는 따로 두되, **사주 리포트 본문은 계산 결과에 묶인 고정 문장**으로
- 과도한 광고·결제 장벽: 점신 최근 리뷰의 63%가 1점, 대부분 광고
- 19금·불륜 콘텐츠: 포스텔러 "바람 펴도 되는지 봐주는 타로"에 장기 사용자 이탈 리뷰

### 4-4. 보험사가 운세를 다룰 때 — 사례와 주의점
**사례**
- 한화생명 다이렉트: 매달 '띠로 보는 이달의 운세'(고든 제공, 입력 없음, 출생연도별 한 줄, 공유 버튼). 이미 사내에 운세 콘텐츠 운영 이력과 톤 기준("~할 수 있어요")이 있다
- 신한라이프: 디지털보험 홈 '자주 찾는 메뉴'에 '오늘의 운세'를 보험 메뉴와 나란히 둠. 기사상 "브랜드 이미지 제고" 목적
- 라이나생명(2017): 50+ 멤버십 혜택으로 신년운세 + 포인트 경품
- 금융권(KB·케이뱅크): 무료 제공, 알림·공유·현금 보상으로 재방문·유입 장치

**주의점**
1. **투자·재무 권유로 읽히는 문장 금지**: 한화생명 8월판 "투자나 거래도 좋은 선택이 될 수 있어요"는 금융사 페이지에서 투자 권유로 오해될 수 있다. KB의 "로또1등 번호 추천"도 보험사엔 부적합. → 재물운 문장은 "지출 점검", "계획 세우기" 수준의 생활 조언으로 제한하는 규칙을 코드에 둔다. (금융 광고 심의 기준과의 관계는 법무·준법 확인 필요 **[미확인]**)
2. **건강운과 보험 상품을 붙이지 않기**: "건강에 신경 쓰라" 문장 바로 옆에 암보험 버튼이 있으면 불안 마케팅이 된다. 운세 결과 화면에 상품 추천을 넣을지 여부는 별도 결정 사항
3. **개인정보**: 생년월일시·출생지·이름 한자는 사실상 개인 식별 정보. 전문가들이 "생년월일 등 민감 정보의 유출과 범죄 악용 가능성"을 지적(매경이코노미 2025-12-11, 정종현 교수), "입력한 데이터가 … 디지털 안전을 위협하는 부메랑"(파이낸셜뉴스 2026-01-04). 보험 마케팅 활용 동의와 운세 이용을 분리하고, 저장 안 함 옵션(정통사주·원광처럼 "서버 저장 없음")을 검토
4. **과의존 경고**: "사주에 결정을 전적으로 맡기면 자기효능감과 문제 해결 의지가 약해질 수 있다"(이준용 전문의, 매경이코노미). 결과 하단에 재미·참고용 안내 + 중대한 결정(건강·투자·법률)은 전문가와 상의 문구
5. **나쁜 운 톤**: 한화생명 기존 톤(가능성 + 조언, 단정 없음)을 기준으로 삼되, "누구에게나 해당되는 말"이 되지 않게 명식 근거 한 줄을 붙인다
6. **AI 고지**: 네이버도 "AI 답변으로 정확하지 않은 정보가 포함될 수 있어요"를 붙인다. 해석 문장이 AI 생성임을 밝히는 문구 필요

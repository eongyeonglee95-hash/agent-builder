## 1. 지금 읽을 책

**첫 책은 현묘 『나의 사주명리』를 권한다. 지금은 이 한 권만 시작해도 된다.** 만세력에서 시작해 음양오행·천간·지지·십신으로 이어지는 목차라 원국표와 해석 용어를 익히는 순서가 분명하다. 신년운세 해석까지 한 권으로 끝나는 책은 아니다. [상품·목차](https://www.yes24.com/product/goods/115027802)

기초를 마치면 같은 저자의 **『나의 사주명리 : 심화 편』**으로 관계·용신·대운·세운을 이어 읽는다. 다른 설명과 실전 사례가 필요할 때 **김원 『혼자 시작하는 사주명리 공부』**를 참고한다. 김원 책을 이미 갖고 있거나 사례 중심 학습이 잘 맞으면 그 책을 주교재로 시작해도 된다. 세 권을 한꺼번에 구입하거나 기초 부분을 모두 반복해서 완독할 필요는 없다. [현묘 심화 목차](https://m.yes24.com/goods/detail/119652155), [김원 목차](https://www.yes24.com/product/goods/110796010)

추천 순서는 **공개 목차와 프로젝트 목표를 비교한 학습 설계 판단**이다. 책을 모두 읽은 독후평이나 저자 해석의 적중률 평가가 아니다.

## 5. 내가 직접 공부해야 하나

**입문서 한 권은 직접 읽는 편이 좋다.** 에이전트가 사용하는 단어와 근거를 구분할 만큼 알아야 결과를 검수하고 제품의 설명 방식을 정할 수 있다. 전문 상담가 수준의 암기나 독자적인 만세력 계산은 필요하지 않다.

| 사람이 이해하고 결정할 것 | 코드·AI가 도울 것 |
|---|---|
| 원국·일간·십신·월령의 역할, 결과표에서 무엇을 보는지 | 음양력·시간대·절입을 반영한 계산과 표 작성 |
| 출생 시각 모름, 달력·자시 정책에 따라 어떤 설명을 보류해야 하는지 | 선택한 정책을 기록하고 경계 사례를 반복 계산 |
| 강약·용신에 여러 해석이 있다는 점과 프로젝트가 채택한 입장 | 출처별 규칙·조건·예외를 대조하고 선택한 규칙을 재현 |
| 해석 문장의 근거를 확인하고 단정·과장을 고치는 일 | 근거가 주어진 설명 초안, 출처 누락·값 모순 검사 |
| 사용자가 알아듣는지, 도움이 되는 표현인지 판단 | 결과 정리와 비교표·리포트 생성 |

동일한 계산 결과와 동일한 해석 규칙이 재현되는 것, 문장이 그럴듯하게 느껴지는 것, 미래 사건의 예측이 입증되는 것은 서로 다른 평가다. 우리의 학습 목표는 먼저 계산과 해석의 연결을 설명하고 검토할 수 있는 수준이다.

## 6. 공부 순서 — 첫 순회 4~6주 예시

하루 30분 정도를 주 4~5회 확보한다고 가정한 **일정 제안**이다. 숙달 기간을 보장하는 것이 아니며, 아래 확인 기준을 설명할 수 있을 때 다음 단계로 넘어간다.

| 단계 | 책에서 읽을 범위 | 기존 자료 연결 | 직접 해볼 것·이해 확인 |
|---|---|---|---|
| 1. 원국 읽기 | 현묘 입문 1~4장. 처음에는 글자별 성격 묘사 암기보다 표의 구조 | [입문](00_입문.md)의 사주 부분, `wiki/basics/` | 검증된 예시 원국에 연·월·일·시와 일간 표시. 일간과 일주의 차이, 출생시각이 틀리면 달라질 부분 설명 |
| 2. 관계 읽기 | 입문 5장 십신 → 심화의 간지 상호작용. 김원 책을 쓰면 3~4강 | [십신](../wiki/relations/ten-gods.md), `wiki/relations/`의 합충 | 계산된 관계와 전통적 해석을 나눈 5행 표. 십신이 일간에 대한 관계임을 설명하고 합·충만으로 길흉 확정하지 않기 |
| 3. 판단 비교 | 심화의 자리·균형·용신. 김원 사례는 필요한 부분만 | [강약](../wiki/judgment/day-master-strength.md), [용신](../wiki/judgment/useful-god.md) | 동일 명조를 두 가지 규칙으로 읽을 때 갈리는 이유 한 장. 오행 개수가 적다는 이유만으로 용신을 확정하지 않기 |
| 4. 2027 해석 검수 | 심화의 운 적용, 김원 사례 한두 개의 판단 과정 | [대운·세운·월운](../wiki/judgment/luck-cycles.md), [신년운세 초안](../wiki/judgment/annual-fortune-method.md) | 검증된 계산 출력에서 짧은 해석 3문장을 골라 계산값·규칙·출처·불확실성 연결. 절기월과 달력월, 교운 전후를 구분 |

예시는 기존 계산 검증 자료에서 고른다. 기존 초안에 적힌 명식을 새로 검산한 것으로 보고하지 않고, 계산 출력·버전·정책을 확인하지 못한 부분은 확인 전으로 표시한다. 출생 시각을 모르면 임의로 채우지 않는다.

프로젝트의 다섯 렌즈 구상은 유지하되, 독서는 사주 한 체계의 계산 → 해석 → 근거 연결부터 마친다. 자미두수·점성술·성명학·타로까지 동시에 배우는 과정을 선행 조건으로 만들지 않는다.

## 7. 다음에 책으로 메워야 할 빈틈

지금은 기초 개념을 더 수집하기보다 다음 세 가지를 독서·감수로 확인할 가치가 있다.

1. **실제 판단 순서**: 저자는 원국에서 무엇을 먼저 보고, 어떤 조건에서 다음 판단으로 넘어가는가? 우당 공식 소개에는 월지·명조 짜임·강약·격국·용신·운 적용 순서가 공개돼 있어 조사 단서가 된다. 이 순서는 해당 저자 체계이며 프로젝트 채택 규칙과 동일하다는 뜻은 아니다. [저자 설명](https://www.woodanglab.co.kr/)
2. **용신 선택이 갈리는 이유**: 억부와 조후의 결론이 다를 때 각 저자의 조건과 예외를 확인한다. 현묘 심화·김원 사례·우당 사례를 필요한 부분만 비교하고 책·장·쪽·본인 요약을 남긴다. 이번에는 책 본문 대조를 수행하지 않았다.
3. **원국에서 세운 문장으로 넘어가는 근거**: “이 관계를 이 생활 영역으로 읽는 이유”와 “어떤 조건이면 그 설명을 쓰지 않는지”를 함께 기록한다. 제품용 점수 가중치와 책의 해석 근거를 분리한다.

현대 책을 읽고 비교하는 것과 책 전체를 자동 수집해 서비스 지식베이스로 넣는 것은 별도 작업이다. 이번 결과는 공개 서지·목차·소개 링크와 자체 요약이며 원문 본문을 수집하지 않았다.

## 8. 재사용과 확인 범위

[saju-research 스킬](../skills/saju-research/SKILL.md)에 기존 조사 검색, 출처 확인 수준, 서점 순위 기준, 학습 경로, 학파·승인 결정 분리, 기존 Claude 인계 절차를 정리했다. 프로젝트 안의 스킬 원본이며 전역 설치나 실행 중인 Claude의 자동 로드를 설정한 것은 아니다. 기존 Claude도 이 파일을 직접 읽어 같은 절차를 사용할 수 있다.

- 공개 원문 확인: YES24 주간 목록·개별 상품 서지/목차/소개, 저자 소개 페이지. 책 전문 독서는 수행하지 않음.
- 디자인 검수: 이번 작업에서 화면 제작·검수하지 않음.
- 데이터 연결: 계산 엔진·도서 API·LLM 연결을 구현하지 않음.
- 동작: 재사용할 조사·학습 지침 작성. 개인 신년운세 생성이나 앱 실행은 이번 범위가 아님.
- 검증 결과와 기존 Claude 수신 상태는 [협업 인계](../CODEX_HANDOFF.md)의 완료 기록을 따른다.

## 변경 이력

- 2026-10-30: 기존 조사와 겹치는 범위를 연결하고, 현재 서점 표시·도서 용도·최소 독서 순서·추가 검토 질문을 작성.

# 09. 사주핑 화면 분석 (사용자 캡처 24장)

확인: 2026-10-30 · 출처: 사용자가 직접 설치·가입해 찍은 화면 24장(원본은 저장소에 넣지 않음, 개인정보 포함) · 운영사: (주)원테라피(카카오 로그인 화면 표기)

## 흐름

```
사주 등록: 이름 → 성별 → 생년월일(음력 체크) → 시간 → 태어난 도시
  → "최근 가장 큰 고민" 최대 3개 (애인·짝사랑·이별·건강·결혼·금전·학업·커리어·취업·가치관·직장/친구/가족 관계)
  → 입력 확인
→ 로그인 전 미리보기: 띠 캐릭터 + "검은 쥐 · 임자(壬子)" + 일주 한 줄("생각은 깊은데, 아무한테도 안 보여줘요") + 원국표
→ 로그인 벽 (카카오·애플·구글)
→ 푸시 알림 설정 (오늘의 운세, 연애·인간관계 흐름, 중요한 날, 사고수·구설수 조심, 핑 만료, 개인화 메시지 — 기본 전부 켬)
→ 채팅 화면 (모델 표기 "Route 1.0"): 원국표 + 일주 풀이 + 추천 질문 4개
→ 답변: 결론 먼저 → 이모지 소제목 3~4개 → "OO님께 한마디" → 내 상황을 되묻는 질문 → 접힌 "해석 근거 3"
→ 발견 탭: 유료 리포트 (재화 '핑', 출석 보상, 친구·가족 사주로도 생성)
→ 리포트 미리보기: 원국 → 오행 분포(레이더) → 대운 흐름(지금 표시) → "사주의 열쇠: 지지용신(월지) 申" → 사주에 든 별(문창귀인·육충 + 흐림) → 글자들의 인연(인·신 형, 인·신 충) → 시기별 흐름·인연 흐름 그래프(흐림, 잠금)
→ 100핑(50% 할인, 평생 소장), 생성 30분~수 시간, 완성되면 알림
```

## 눈여겨볼 점

1. **고민 3개 선택**이 답변 전체의 맥락이 된다. 첫 답이 바로 커리어·금전으로 들어간다. 조사에서 나온 "지금 내 상황을 짚을 때 소름"을 입력 한 번으로 만든다.
2. **판정 보류를 근거로 보여준다.** 해석 근거 칩: "편인격 — 판정 보류(격 미정, 격이 성립하지 않아 판정을 미룬 상태, 용신 주제는 유효하고 격이 서는 운의 시점이 중심)", "대운 39-48 향배", "세운 2026 향배". 판단을 구조화해 두고 LLM이 문장을 쓰는 구조로 보인다(내부 구조는 미공개).
   → 앞서 "판단까지 코드로 하는 서비스는 확인되지 않았다"고 한 판단은 고친다. 사주핑은 적어도 근거·판정 상태를 구조로 노출한다.
3. **시기를 단정한다.** "독립에 가장 잘 맞는 해는 2028년" — 소름 포인트(시기)를 정면으로 쓴다. 우리 원칙(C13, 단정 금지)과 다른 선택.
4. **되묻기**: 답 끝에 "직장 유지하며 준비 중인지, 완전 독립인지" 묻는다. 대화를 이어가는 장치이자 개인화 수집.
5. **띠 캐릭터 + 일주 한 줄**이 첫인상. 공유 카드 역할.
6. **흐림(blur) 미리보기**로 결제 유도. 시기별 흐름·인연 흐름 그래프를 흐리게 보여줌.
7. **알림에 공포 항목**(사고수·구설수 조심)이 기본으로 켜져 있다 — 우리 금칙어 방향과 반대.

## 우리 컨셉에 주는 것

- 가져올 것: 고민 선택(입력 1단계), 결론 먼저 쓰는 답 구조, 접힌 근거 칩, 판정 보류를 숨기지 않는 표시, 되묻기.
- 다르게 갈 것: 시기 단정, 공포 알림, 흐림 결제 유도, 로그인 벽, 생성 대기 30분.
- 겹치는 것: 근거 노출·판정 보류는 이미 사주핑이 한다 → 우리 차별점은 "근거"가 아니라 **두 개의 나(간극)** 와 **절기 연재·회고**에 둔다.

# 06. 웹툰형·스토리형 운세 결과 조사 — "이렇게까지 할 필요가 있나?"

- 작성: 2026-10-30 (Claude 리서치 에이전트)
- 질문: 운세 결과를 웹툰·만화 컷·세로 슬라이드 카드로 보여주는 서비스는 어떤 게 있고, 우리 2027 신년운세 PoC 1차에 넣을 가치가 있나?
- 확인 방법: 웹 검색 + 기사·공식 페이지 본문 열람. **확인일은 따로 적지 않으면 모두 2026-10-30.**
- 표기: 대행사 블로그·가격 집계 사이트처럼 믿기 어려운 출처는 "(약한 출처)". 찾지 못한 것은 "미확인". 화면 흐름 그림(ASCII)은 기사 설명을 바탕으로 **내가 다시 그린 것**이며 실제 화면을 그대로 옮긴 게 아니다.
- 스크린샷: 새로 찍지 않았다. 같은 폴더 `img/hanwhalife_direct_tti_event.jpg`(다른 조사에서 캡처한 한화생명 "띠로 보는 이달의 운세")를 참고했다.

## 0. 결론 먼저

1. **"사용자 사주로 만화를 실시간 생성"하는 서비스는 국내외 모두 확인하지 못했다.** 실제로 나와 있는 건 (a) 기존 웹툰 캐릭터가 말투로 운세를 전해 주는 것(타로툰), (b) 사진을 웹툰 그림체로 바꿔 주는 것(네이버웹툰 AI 캐리커처), (c) 세로 슬라이드 결산 카드(Spotify Wrapped), (d) 공유용 한 장 카드(Co–Star, 케이뱅크 신년운세 링크 공유) 정도다.
2. **공유·참여 효과가 숫자로 확인된 형식은 "세로 슬라이드 카드 + 한 장 공유 이미지"다.** Spotify Wrapped 2025는 첫 24시간 2억 명 이상 참여, 공유 5억 회 이상(스크린샷·다운로드 포함)이다. 웹툰형 운세의 공유 성과 숫자는 찾지 못했다.
3. **만화풍은 "믿음"을 깎을 수 있다는 연구가 있다.** 2025 IEEE VIS 연구에서 만화풍 막대·손글씨 글꼴은 차트의 신뢰도를 크게 떨어뜨렸다. "진짜 그럴듯한 운세"가 목표라면 만화 컷을 리포트 본문에 쓰는 건 역효과가 날 수 있다.
4. **생성형 이미지 실시간 생성은 1차엔 맞지 않다.** 장당 약 $0.04~0.13, 1장에 십수 초(측정 사례 평균 15.5초), 긴 한글 말풍선은 아직 깨진다는 평가, AI 생성물 표시 의무(AI 기본법, 2026-01-22 시행)까지 붙는다.
5. **추천: 1차는 "2027 한 장 요약 공유 카드" + 리포트 앞쪽 5~7장짜리 세로 슬라이드(HTML/CSS)만.** 그림은 미리 그린 12지 캐릭터·배경 몇 장을 고정으로 쓰고, 글자는 우리가 HTML로 얹는다. 4~6컷 웹툰과 생성형 이미지는 2차.

## 1. 사례

### 1-1. 타로툰(Tarotoon) — 네이버웹툰 자회사 스튜디오 리코 (국내, 가장 가까운 사례)

- 출시 2025-06-10. 스튜디오 리코가 내놓고 플랩스AI가 개발한 웹 서비스. 웹툰 캐릭터가 사주·타로를 전해 준다.
- 캐릭터 말투와 성격을 반영한 맞춤 운세 리포트, 시나리오 흐름에 따라 타로카드 모양 선택지가 나오는 대화형 구성, 운세를 본 뒤 원작 웹툰으로 연결.
- 출시 IP 4종: 냐한남자, 마루는 강쥐, 작전명 순정, 진돌히디만화.
- 리포트 뒤 받는 '행운카드'를 모아 도감을 채우면 쿠키 200개, 신규 가입 쿠키 300개.
- 출처: [네이버 보도자료](https://www.navercorp.com/media/pressReleasesDetail?seq=32573), [쿠키뉴스 2025-06-11](https://www.kukinews.com/article/view/kuk202506110020), [파이낸셜뉴스](https://www.fnnews.com/news/202506112114292592)

```
[캐릭터 고르기] → [캐릭터가 말 걸기: 생년월일 물어봄]
      → [타로카드 모양 선택지 고르기] → [캐릭터 말투로 쓴 운세 리포트]
      → [행운카드 받기(도감)] → [원작 웹툰 보러 가기]
```

| 항목 | 내용 |
|---|---|
| 컷 수·분량 | 미확인 (기사에 "웹툰 컷"이라는 말은 없고 "인터랙티브 구성"이라고만 함) |
| 개인화 | 운세 글은 개인화. 이름·사주 글자가 그림에 들어가는지, 캐릭터가 사용자를 닮게 그려지는지는 미확인(정황상 기존 캐릭터 그림을 그대로 씀) |
| 그림 방식 | 원작 캐릭터 그림 사용(미리 그린 것) — 실시간 생성 여부 미확인 |
| 공유 장치 | 행운카드 도감(수집). SNS 공유 기능은 미확인 |
| 성과 수치 | 미확인 |

**읽을 점:** 네이버웹툰조차 "캐릭터가 대화로 전해 주고 카드 한 장을 준다" 수준에서 멈췄다. 사주로 만화를 새로 그려 주지는 않았다. 강점은 이미 팬이 있는 캐릭터 IP다 — 우리에겐 그게 없다.

### 1-2. 네이버웹툰 "AI 웹툰 캐리커처" (국내, 사진 → 웹툰 그림체)

- 출시 2024-07-22. 얼굴 사진 1장 → 1~2분 안에 캐리커처 6장. 1회 2,000원. 조석 그림체로 시작, 2024년 9월 이말년 그림체 추가 예정.
- 출시 3주 누적 방문 50만 명 이상. 1주 매출이 이전 AI 사진 서비스('이번생엔 로판여주', 3~7월) 4개월 매출보다 많았다.
- 결과를 웹툰 컷 틀에 넣어 저장 가능(조석 틀엔 캐릭터 대사 포함).
- 출처: [뉴시스 2024-08-20](https://www.newsis.com/view/NISX20240820_0002855670)

**읽을 점:** "내 얼굴이 웹툰에 나온다"는 확실히 먹힌다(3주 50만). 하지만 (1) 운세가 아니고, (2) 유명 작가 그림체라는 IP가 핵심이며, (3) 얼굴 사진을 받으면 우리 쪽에 초상·개인정보 부담이 생긴다(3-4절).

### 1-3. 기타 국내 AI 사주 + 캐릭터

- **청월아씨·월하소녀(로켓AI)**: 2025년 6월 보도에서 "명리학을 웹툰처럼 풀어낸" 사주 서비스로 소개됐다는 검색 요약이 있으나, 기사 본문은 확인 못 함 → **미확인**.
- **헬로우봇**: 판다 '판밍밍', 잎사귀 '풀리피' 등 캐릭터마다 말투를 달리한 챗봇 운세. 출처: [디아이투데이](https://ditoday.com/%EC%98%A4%EB%8A%98%EC%9D%80-%EC%95%88%EB%85%95%ED%95%A0-%EA%B1%B0%EC%98%88%EC%9A%94-%ED%97%AC%EB%A1%9C%EC%9A%B0%EB%B4%87). 누적 사용자 500만 명이라는 기사 언급이 있으나 시점 불명([캐릿](https://www.careet.net/1161)) → 시점 미확인. 만화 컷 결과 화면은 미확인.
- **"내 사주로 만든 웹툰" 유행**: 2025년 봄 ChatGPT 지브리풍 유행으로 국내 ChatGPT 일간 사용자 120만 명([The Star 2025-04-03](https://apimaster.thestar.com.my/aseanplus/aseanplus-news/2025/04/03/chatgpt-hits-12-million-daily-users-in-s-korea-amid-ghibli-style-ai-generated-image-trend))은 확인되나, "사주를 만화로" 유행 자체는 기사로 확인 못 함 → **미확인**. 프롬프트 갤러리(캐럿)에 사주 리포트 카드·4컷 만화 프롬프트는 있다([carat.im ai-saju](https://carat.im/prompt-gallery/ai-saju)).

### 1-4. 금융사 신년운세 이벤트 (국내)

**케이뱅크 × 포스텔러 '2026 신년운세'** — [블록미디어 2025-12-30](https://www.blockmedia.co.kr/archives/1026176)
- 정가 2만2천 원 상당 사주 콘텐츠를 앱에서 무료. 이름·성별·양력 생년월일 입력(한 번 넣으면 못 바꿈).
- 신년 총운 + 재물·건강 등 5개 분야 + 1~12월 월별 운세. 앱에 저장돼 다시 보기 가능.
- **공유 장치: 이벤트 링크를 친구에게 보내고, 친구가 처음 운세를 보면 최대 1,000원 랜덤 현금.** 결과 이미지 공유가 아니라 "링크 + 보상" 방식.
- 웹툰·만화 형식: 기사에 없음. 참여자 수 미확인.

```
[혜택 탭 배너] → [이름·성별·생일 입력] → [총운] → [5개 분야] → [1~12월]
                                                 └→ [친구에게 링크 공유 → 랜덤 현금]
```

**신한라이프 운세** — 로그인 없이 무료, 정통·생활·애정 3갈래, 긴 텍스트·금전운 특화로 소개됨. 만화형 아님. 이용자 수 미확인. 출처: [에스콰이어 코리아 2026-01-31](https://www.esquirekorea.co.kr/article/1896492), [신한금융 인사이트(자사 홍보)](https://www.shinhangroup.com/kr/archive/insight/extend/detail/33324)

**한화생명 '띠로 보는 이달의 운세'(2026년 8월호)** — `img/hanwhalife_direct_tti_event.jpg` 참고(원 URL은 해당 캡처를 남긴 조사 문서 참조, 여기선 미확인). 3D 12지 캐릭터 + 띠별 한 줄 + 출생연도별 한 줄의 **세로 카드뉴스형**. 개인화는 띠·출생연도까지. 이미 사내에 "캐릭터 + 짧은 문장 카드" 자산과 톤이 있다는 뜻이라 우리 공유 카드의 출발점으로 쓸 만하다.

**카카오·토스**: 2026 신년운세 웹툰형 이벤트는 찾지 못함 → 미확인. 참고로 카카오는 2015년 다음앱 신년운세 이벤트(카톡 공유)를 했고([카카오](https://www.kakaocorp.com/page/detail/7884?lang=ENG)), 2026-10-12~11-02 이모티콘 캐릭터 카드 뽑기(카드 공유·저장, 캡처 해시태그 SNS 이벤트)를 진행 중([카카오](https://www.kakaocorp.com/page/detail/12159)). 토스는 카톡 링크 공유가 "신뢰하지 않는 페이지"로 표시된 분쟁이 있었다([아주경제 2025-05-07](https://www.ajunews.com/view/20250507104649982)) — **공유를 카톡 링크에만 기대면 막힐 수 있다**는 점은 참고.

### 1-5. 심리테스트류 결과 카드 (국내)

- 캐릿 2020-03-24 기사: 심리테스트가 자발적 참여·인지도에 효과적이라는 업계 인터뷰(본문 유료) — [캐릿](https://www.careet.net/31).
- 케이테스트·푸망·스푼라디오 테스트별 참여자 수: 미확인.

### 1-6. Co–Star (해외, 공유 카드의 원조격)

- 2019-10 기준 다운로드 340만 이상, 인스타 팔로워 87만 이상, 참여율 7% 이상(Priori Data·Ninjalitics 인용).
- 바이럴 장치: (1) 날카롭고 짓궂은 짧은 푸시 문장이 캡처돼 퍼짐, (2) 캡처해 올릴 때 계정 태그를 유도, (3) 운세를 앱에서 바로 SNS로 보내는 **비주얼 카드**, (4) 친구 초대 궁합.
- 출처: [OMR 2019-10-25](https://omr.com/de/daily/co-star-app-viral). 상세는 같은 폴더 `02_해외_점성술_AI운세.md`.
- 그림: 만화가 아니라 흑백 미니멀 디자인. **"웹툰이 아니어도 문장 하나가 날카로우면 공유된다"**의 예.

```
[오늘의 한 줄 푸시] → [앱: 오늘 운세 Do/Don't] → [공유 버튼 → 흑백 카드 이미지] → 인스타 스토리
```

### 1-7. Spotify Wrapped (해외, 세로 슬라이드 결산의 기준점)

- 형식: 인스타 스토리처럼 탭으로 넘기는 세로 카드("stories"). [Desirability Lab](https://desirabilitylab.com/backfill/backfill-2021-89-spotify-wrapped-campaign)
- **2025**: 2025-12-03 출시, 24시간 만에 참여 2억 명 이상(참여 = 스토리 1장 이상 본 사람), 공유 5억 회 이상(전년 대비 +41%, 앱 내 공유 + 스크린샷 + 다운로드 포함). [TechCrunch 2025-12-04](https://techcrunch.com/2025/12/04/spotify-says-wrapped-2025-is-its-biggest-yet-with-200m-users-in-its-first-day)
- **2024**: 2억 명 도달에 62시간(위 TechCrunch). 최종 참여 약 2억4,500만 명(Business Insider, 미러 페이지로만 확인 → 약한 출처).
- **역효과 사례**: 2024년 Wrapped는 "통계가 얇고 AI 팟캐스트 기능"으로 혹평을 받았고, 2025년엔 소비자용 AI 기능 없이 데이터 스토리를 늘려 반등했다(위 TechCrunch). → **사람들은 "AI가 만든 것"보다 "나에 대한 정확한 숫자·사실"에 반응**했다.
- 제작: 1년 넘게 디자이너·데이터 과학자·마케터가 준비(Business Insider, 약한 출처). 장 수는 미확인.

```
[1. 올해 들은 시간] → [2. 최애 장르] → [3. 최애 아티스트] → ... → [마지막: 한 장 요약 카드] → [공유]
   (각 장: 큰 숫자/이름 1개 + 짧은 문장 + 강한 색 배경, 탭으로 넘김)
```

## 3. 판단 근거

### 3-1. 효과 — 만화가 도움이 된다는 쪽
- 건강 정보에서 만화형이 이해·관심을 높였다는 작은 연구들: CDC 학회 초록(성인 예방접종 전단, 무작위 265명, 만화형이 더 긍정 평가) [CDC](https://cdc.confex.com/cdc/nphic16/webprogram/Paper37139.html), St Andrews 2024 인터랙티브 데이터 만화(암 데이터 기억·이해 향상) [St Andrews](https://research-portal.st-andrews.ac.uk/en/publications/interactive-data-comics-for-communicating-medical-data-to-the-gen/). 대부분 소규모·단일 기관이라 "그럴 수 있다" 수준.
- 몰입·공유: 숫자로 확인된 건 Wrapped식 세로 카드(1-7)와 "내 얼굴 웹툰"(1-2). 웹툰형 **운세**의 공유 수치는 미확인.

### 3-2. 역효과 — 우리 목표("진짜 그럴듯함")와 부딪히는 쪽
- **신뢰도 하락**: 2025 IEEE VIS(Song·Cho·Bearfield·Stasko) — 만화풍 막대와 손글씨 글꼴이 차트 메시지 신뢰도를 "크게 떨어뜨림", 색상은 높임. 효과는 맥락에 따라 다름. [IEEE VIS 2025](https://aa.ieeevis.org/year/2025/program/paper_de570d65-b80f-4e25-9d54-88f11281e2c5.html). 운세 대상 실험은 아니지만, "정통 사주 리포트"의 권위감을 만화가 깎을 수 있다는 방향 근거.
- **웃는 얼굴 그림이 이해를 떨어뜨린 사례**: 환자 교육 웹페이지의 웃는 얼굴 사진이 고령층 이해도를 낮춤(일리노이대) [Illinois](https://news.illinois.edu/images-on-health-websites-can-lessen-comprehension-study-finds/). 장식 그림이 늘 득은 아니다.
- **"AI 티"에 대한 반감**: Spotify 2024 Wrapped의 AI 팟캐스트 혹평 → 2025 AI 빼고 반등(1-7).
- **로딩**: 생성형이면 첫 컷까지 10~30초. 리포트 본문보다 그림을 더 오래 기다리게 된다.
- **비교 대상이 이미 텍스트형**: 케이뱅크·신한라이프 등 금융사 운세는 모두 텍스트+월별 구조. 사용자가 "정통"을 느끼는 기준이 그쪽이다.

### 3-3. 보험사 브랜드 관점
- 운세 화면 안에 보험 가입 유도가 섞이면 "불안 마케팅"처럼 보일 수 있다(예: 만화 컷에서 "건강운 나쁨 → 보험"). 만화는 감정 연출이 강해 이 위험이 더 크다. 보험 광고 심의 기준과의 관계는 이번에 확인 못 함 → **미확인, 사내 준법 확인 필요**.
- 한화생명은 이미 3D 12지 캐릭터 운세 카드뉴스를 쓰고 있다(1-4). 새 캐릭터를 만들기보다 같은 톤을 맞추는 게 브랜드상 안전하다. 그 캐릭터 저작권·사용 범위(외주 계약)는 미확인 → 확인 필요.

[뉴시스 2026-01-21](https://mobile.newsis.com/view/NISX20260121_0003484769). → **(b)를 쓰면 공유 이미지에도 표시를 붙여야 한다.** (a)(c)(d)는 사람이 그린 그림이면 해당 없음(텍스트를 LLM이 쓰는 부분의 고지는 리포트 전체 차원에서 별도 검토).

## 4. 제안

### 1차에 넣을 것 (작고 확실한 것)
1. **"2027 한 장 요약" 공유 카드 1장** (Co–Star·Wrapped 마지막 장 방식)
   - 내용: 이름(선택), 일간 한자 1글자 + 오행 색, 2027 키워드 3개, 한 줄 요약, 좋은 달/조심할 달, 하단 "재미로 보는 운세" 문구.
   - 그림: 띠 캐릭터 1장(미리 준비) 또는 그림 없이 타이포만. 글자는 전부 HTML → 이미지 변환(한글 깨짐 없음).
   - 공유: 이미지 저장 + Web Share API. 카톡 링크 공유에만 의존하지 않기(1-4 토스 사례).
2. **리포트 첫머리 5~7장 세로 슬라이드** (Wrapped식, (d))
   ```
   [1. 당신의 일간 丙火]  [2. 2027 丁未년과 나의 관계]  [3. 키워드 3개]
   [4. 상반기/하반기]     [5. 조심할 달 · 좋은 달]      [6. 한 장 요약 → 공유]
   → 그 아래로 기존 5렌즈 상세 리포트(텍스트·표·그래프, 진지한 톤)
   ```
   - 장마다 "진짜 계산 결과" 한 개를 크게 보여줘서 만화 대신 **데이터로 그럴듯함**을 만든다.
3. 공유 이미지 생성은 서버(Python, 예: HTML→PNG) 또는 브라우저(canvas) 중 구현 편한 쪽. 이미지 생성 API 호출 없음.

### 2차로 미룰 것
- **4~6컷 웹툰(방식 a)**: 12지 캐릭터·표정 컷 라이브러리를 사내 디자인/외주로 확보한 뒤, LLM이 고른 컷 번호 + 말풍선 문장만 넣는 방식. 1차 공유 카드의 공유율을 먼저 보고 결정.
- **생성형 이미지(방식 b)**: 하더라도 "공유 카드 배경 1장" 정도부터, 글자는 넣지 않고, AI 생성 표시 붙이고, 배치 요금·캐시(같은 일간×띠 조합은 재사용)로 비용 관리. 실시간 6컷은 비추천.
- **얼굴 사진 → 닮은 캐릭터**: 개인정보·초상권 검토 전에는 보류.

### "이렇게까지 할 필요가 있나?"에 대한 답
- **웹툰 자체는 필요 없다.** 확인된 성공 사례들(Wrapped, Co–Star)은 만화가 아니라 "나에 대한 짧고 정확한 한 문장/숫자 + 공유하기 좋은 한 장"으로 퍼졌다. 웹툰형 운세(타로툰)는 유명 IP가 있어야 성립하고, 성과 숫자는 공개된 게 없다.
- **공유 카드 한 장 + 짧은 세로 슬라이드는 할 가치가 있다.** 비용이 거의 없고, 그럴듯함을 해치지 않으며, 퍼질 장치가 된다.

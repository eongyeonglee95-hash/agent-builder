## 1. Co–Star

### 1-1. 입력·온보딩
ScreensDesign의 화면 기록 기준 순서 ([ScreensDesign Co–Star](https://screensdesign.com/apps/costar-personalized-astrology/)):

```
[환영: 오늘의 조언 카드 + Get Started]
   → [생년월일: 휠 피커]
   → [출생 시각: 시간 피커 + 개인정보 안내 + Continue / Skip]   ← 시각 모름 = "Skip"
   → [출생지: 검색창 + 자동완성 목록 (예: New York City)]
   → ["Building Your Chart" 애니메이션]
   → [내 배치·성격 요약 + NASA 데이터 고지]
   → [전화번호/Apple 로그인]
   → [알림 켜기]
   → [친구 추가 + 연락처 권한]
```
- 이름 입력 단계는 화면 기록에 없음.
- 출생 시각을 "Skip"하면 내부적으로 어떻게 처리하는지(정오 가정 등)는 **미확인**. App Store 편집자 소개는 "분 단위 출생 시각"을 강조 ([Apple 스토리](https://apps.apple.com/us/story/id1458814851)).
- 앱 출시 당시 창업자 인터뷰에서 "출생 시각을 모르면 엄마에게 문자하라"는 문구가 인용됨 — 정책이라기보다 브랜드 말투 ([Dazed](https://www.dazeddigital.com/life-culture/article/39881/1/costar-is-the-new-astrology-app-banu-guler-vfiles)).

### 1-2. 결과 화면
- 홈: 상단 날짜 선택 → 그날 운세 + **두 칸짜리 조언 목록**(흔히 Do / Don't로 알려짐) + "Dive Deeper" 버튼. 가족·일 등 영역 탭 ([ScreensDesign](https://screensdesign.com/apps/costar-personalized-astrology/)).
- 차트: 프로필의 Chart 탭. 행성 배치 표 + 원형 차트. 각도 설명 예: "Moon과 natal Mercury의 sextile" 식으로 **근거 행성 관계를 문장 옆에 노출**.
- The Void(질문 기능): 검은 원 버튼 → 밤하늘 화면에서 질문 입력 → 답변 + **답의 근거가 된 행성 도식**을 함께 보여줌. 질문 분류: Existential / Self / Relationship / Work / Social ([Bustle 2023-05-23](https://www.bustle.com/life/co-star-astrology-app-ai-feature), [ScreensDesign](https://screensdesign.com/apps/costar-personalized-astrology/)).
- 하우스 체계: **Porphyry**. Placidus·Whole Sign은 미지원(2021년 인터뷰 기준) ([The Astrology Podcast Ep.286 전사본](https://theastrologypodcast.com/?p=11392)).

```
┌──────────────────────────────┐
│  < 화 수 [목] 금 토 >          │  ← 날짜 이동
│                              │
│  오늘 한 줄 (짧고 단정적)       │
│                              │
│  ┌─ 이것 ─┐  ┌─ 저것 말고 ─┐   │  ← 2칸 조언 목록
│  │ ...   │  │ ...        │   │
│  └───────┘  └────────────┘   │
│  [Dive Deeper]               │
│  영역 탭: 일 · 사랑 · 가족 …   │
│        ( ● ) The Void        │  ← 하단 가운데 질문 버튼
└──────────────────────────────┘
```

### 1-3. "소름" 장치
- **푸시 알림 한 줄**이 핵심. 하루 1회, "가장 강한 트랜짓 + 내 배치"를 조합 ([Astrology Podcast Ep.286](https://theastrologypodcast.com/?p=11392)).
- 실제 문장 예:
  - "You seem stressed, and that stress seems like it's filling you with regret, or maybe confusion." ([Inverse 2019-04-18](https://inverse.com/article/54991-costar-astrology-app-how-it-works))
  - "Trouble in Sex & Love: Ask yourself why you have different expectations for people you sleep with than for people you don't." ([Business Insider](https://businessinsider.nl/ive-been-using-ai-astrology-app-made-my-life-better-2019-7/))
  - "Correct all the time-wasting at your job." ([Inverse](https://inverse.com/article/54991-costar-astrology-app-how-it-works))
- 이 문장들이 트위터·인스타에서 수만 좋아요를 받으며 바이럴 ([OMR](https://omr.com/de/daily/co-star-app-viral)).
- 친구 궁합: 연락처에서 친구를 불러와 서로 차트 비교 → "나만 아는 이야기"를 친구 관계로 확장.

### 1-4. 나쁜 운 표현
- "problem areas(문제 영역)" 목록을 따로 보여줌 ([Inverse](https://inverse.com/article/54991-costar-astrology-app-how-it-works)).
- 창업자 Banu Guler: 목적은 "불안을 주는 게 아니라 주의를 틀어주는 것(swerve their attention)". 너무 날 선 문장("Start a cult")은 피드백 후 폐기, 팬데믹 이후 톤을 "dialed back" ([Astrology Podcast Ep.286](https://theastrologypodcast.com/?p=11392)).
- 리뷰 불만: 부정적 톤이 불안을 키운다는 의견이 반복 ([Kimola 리뷰 분석](https://kimola.com/reports/co-star-app-review-analysis-unveiling-user-insights-app-store-us-155484), [UvA Masters of Media 2021](https://mastersofmedia.hum.uva.nl/2021/10/the-fault-in-our-stars)) (약한 출처 포함).

- 2019 기사: 프리랜서 작가·점성가 그룹이 행성 데이터를 짧은 문장으로 압축 ([Inverse](https://inverse.com/article/54991-costar-astrology-app-how-it-works)). 2021 인터뷰: 푸시 문장은 "작가 두 명이 여러 버전을 써서 테스트" ([Astrology Podcast](https://theastrologypodcast.com/?p=11392)).
- The Void(2023-05-04 출시): "점성 해석 데이터베이스"에서 꺼내 조립. 사용 AI 모델은 **미공개** ([Bustle](https://www.bustle.com/life/co-star-astrology-app-ai-feature)).
- Swiss Ephemeris 사용 여부: **미확인**.
- 2026-07-24 Bloomberg: 이미지 생성 AI 회사 **Midjourney가 Co–Star 인수**(봄에 종료, 금액 비공개). Bloomberg는 Co–Star를 "AI와 사람 글쓰기의 조합"으로 설명 ([Bloomberg Law](https://news.bgov.com/mergers-and-acquisitions/ai-lab-midjourney-buys-astrology-startup-co-star-plans-new-apps), [Gizmodo](https://gizmodo.com/were-at-a-crazy-moment-in-history-midjourney-buys-astrology-app-co-star-2000790434)).

## 2. The Pattern

- 입력: 출생 시각 없이도 진행 가능하다는 화면 기록 언급 ([ScreensDesign 카테고리 요약](https://screensdesign.com/showcase/the-pattern))이 있으나 구체 처리 방식은 **미확인**. 계정 생성 필수, 게스트 모드 없음.
- 결과 화면 ([App Store](https://apps.apple.com/app/id1071085727), [ScreensDesign](https://screensdesign.com/showcase/the-pattern)):
  - Your Pattern(성격), Your Transits(과거·현재·미래 시기), Bonds(친구·연인·유명인과의 관계 강점/도전), Connect(데이팅, "독자 알고리즘"), Time Travel(아무 날짜의 트랜짓, 유료).
  - **"요약은 무료 → Go Deeper+ 버튼 → 유료 장문/오디오"** 구조.
  - Relationship Clarity: 특정 관계에 대해 묻는 **AI 채팅**.
  - 차트 요소를 누르면 설명이 열리는 tap-to-explain.
- 소름 장치: 행성 용어를 숨기고 "당신은 ~한 사람" 식 심리 서술. 리뷰 "scarily accurate" ([Bustle 리뷰](https://www.bustle.com/life/pattern-app-review-features-price)).
- 나쁜 운: 리뷰 중 "건강하지 않은 패턴을 반복해서 말하지만 조언이 없다"는 불만 ([App Store](https://apps.apple.com/app/id1071085727)).
- AI/엔진: 공개 정보 **미확인**.
- 가격: Go Deeper+ 월 $14.99 / 분기 $29.99 / 연 $83.99, Connect+ 분기 $24.99, 프로필 슬롯 3개 $9.99 등. 평점 4.0 / 약 1.6만 건 ([App Store](https://apps.apple.com/app/id1071085727)).
- 불만: 화면이 잘게 쪼개져 탐색 불편, 많은 기능이 유료 ([Bustle](https://www.bustle.com/life/pattern-app-review-features-price)).

- 수익: 구독 Sanctuary+ 월 $14.99 / 연 $49.99, 첫 상담 $4.99, 10분 상담 $29.99~$49.99, 이후 분당 과금. 평점 4.8 / 약 4.4만 건 ([App Store](https://apps.apple.com/app/id1417411962)).

## 4. CHANI

- 입력: 출생 시각 모름 처리 공식 안내 **미확인**. 앱스토어 개발자 답변에서 "그날 일출 시각을 넣으면 태양궁 운세를 읽을 수 있다"고 안내 ([App Store](https://apps.apple.com/us/app/-/id1532791252)).
- 결과 화면: 일일 운세, 행성 트랜짓 해설, 출생 차트 배치별 해설, 주간 운세, Week Ahead 팟캐스트, 타로, **저널 질문**, 의식(ritual), 명상·수면 이야기, 토성 회귀 강좌, **연간(Year Ahead) 리딩 포함**, 친구 차트 100개 저장 ([App Store](https://apps.apple.com/us/app/-/id1532791252)).
- 개인화 방식: 매주 콘텐츠를 **상승궁(rising sign) 기준**으로 맞춤 — 12가지 버전을 사람이 씀 ([白鲸/백경 기사](https://www.baijing.cn/article/54913), [chani.com](https://www.chani.com/app?view=home)).
- AI: **"written by astrologers, not AI"**를 전면에 둠. 2025-10-01 글 "Can AI be your astrologer?"에서 "AI 봇은 틀리는 데 그치지 않고 지어낸다", "AI는 점성술 학파를 구분하지 못한다", "점성술은 인간으로서 목격되는 일" ([CHANI Substack](https://chaninicholas.substack.com/p/can-ai-be-your-astrologer)).
- 나쁜 운: 어려운 트랜짓을 저널 질문·의식과 묶어 "할 일"로 바꿔주는 구성(기능 목록 기준 해석). 구체 문장 규칙은 **미확인**.
- 수익: 월 $11.99 / 연 $107.99. 평점 4.9 / 약 6만 건, Editors' Choice. VC 투자 없음, 매출 5%를 젠더 폭력 생존자에게 기부(누적 $350만+) ([App Store](https://apps.apple.com/us/app/-/id1532791252)).

## 10. 종합

### 10-1. 개인화 체감을 만드는 요소 (근거 있는 것만)
1. **"오늘 나에게만" 짧은 한 문장** — 그날 가장 강한 트랜짓 × 내 배치로 고른 단정적 문장 (Co–Star 푸시). 길이가 짧을수록 공유되고 "찔린다".
2. **근거를 옆에 붙이기** — "Moon sextile natal Mercury"처럼 계산 근거를 작게 노출(Co–Star 차트·The Void 도식, The Pattern·Nebula tap-to-explain). "그냥 지어낸 말이 아니다"라는 신뢰.
3. **사람과의 관계로 확장** — 친구·연인 차트 비교(Co–Star, The Pattern Bonds, CHANI 친구 100명). 내 얘기 + 아는 사람 얘기가 맞으면 체감이 커진다.
4. **기준점이 세밀할수록 맞다고 느낌** — 태양궁이 아닌 상승궁(CHANI), 전체 차트(Hint·TimePassages), 분 단위 출생 시각(Co–Star 홍보).
5. **후속 질문 가능** — 리포트형의 최대 약점이 "맥락 없음". 사람들이 ChatGPT/DeepSeek로 옮겨간 이유가 "추궁·교정 가능" ([白鲸出海](https://news.pedaily.cn/202607/565983.shtml)).
6. **사람 손길 표시** — CHANI "not AI", Sanctuary "not algorithms", TimePassages "real astrologers". 해외에선 'AI가 썼다'가 오히려 신뢰를 깎는 신호로 쓰인다.
7. **반복되면 깨진다** — 같은 틀에 문장만 바뀌면 바로 들킨다(Co–Star 불만). 문장 다양성이 개인화 체감의 하한선.

### 10-2. 연간(트랜짓 기반) 리포트의 일반적 목차 — 관찰 종합
공식 목차를 공개한 곳은 찾지 못함(Co–Star Your Year Ahead, CHANI Year Ahead 목차 **미확인**). 아래는 Astro.com Forecast(외행성 트랜짓, 영역별, 기간 단위), Astrotheme 2년 예보(주요 예보 + 일별 변동 + 달 트랜짓 별첨 + 그래프식 aspectarian, [Astrotheme](https://www.astrotheme.com/detailed_astrology_forecasts/Detailed_2_Year_Forecast)), Click108(紫微 유년 + 별자리 유년 결합), 문묵천기(대한→유년→유월→유일 전환)에서 공통으로 보이는 구조를 묶은 **우리 쪽 정리**다.

```
1. 올해 한 줄 요약 + 키워드 3개
2. 올해의 큰 흐름 (느린 행성 / 대운·유년 — "배경 날씨")
3. 영역별: 일·돈 / 사랑·관계 / 건강·컨디션 / 성장·배움
4. 시기표: 월별(또는 기간별) 강약 그래프 + 주요 날짜 (시작~끝 기간으로)
5. 조심할 시기와 대처 (나쁜 운 = 기간 + 행동 제안)

```

### 10-3. 우리가 가져올 UI 패턴
- **온보딩 한 화면에 한 질문** (생년월일 휠 → 시각 + "모름/Skip" → 출생지 자동완성 → "차트 만드는 중" 애니메이션 → 요약 3줄). Co–Star 순서가 표준.

사용자가 전달한 ZIP의 PNG 24장을 Codex도 모두 열어 확인했다. 상세 화면 목록은 기존 [09 화면 분석](research/09_사주핑_화면분석.md)을 재사용한다. 원본은 임시 경로에서 열람했으며 저장소에 추가하지 않았다. 아래는 화면에서 확인한 범위와 컨셉 검토 의견이다. 사용자 승인이나 Claude의 수신 확인을 뜻하지 않는다.

### 화면 근거와 해석 범위

번호는 원본 PNG 파일명 끝의 001~024다.

| 캡처 | 확인한 내용 | 판단에 적용할 한계 |
|---|---|---|
| 002, 009~010 | 고민 최대 3개 선택, 추천 질문, 사용자의 직업 질문 | 첫 커리어 답변은 직접 질문 뒤에 나왔다. 고민 선택만으로 답변 전체가 개인화됐다는 인과는 이 자료로 확인할 수 없음 |
| 013 | 펼친 해석 근거, 격의 판정 보류, 대운·세운 항목 | 구조화된 표시를 확인. 코드가 판단했는지 LLM이 판단했는지, 원문 출처와 연결되는지는 미확인 |

따라서 기존 대화의 “운세 앱은 후속 질문·계획을 제공하지 않는다”, “재방문 구조를 만들 동기가 없다”는 일반화는 차별화 근거에서 제외하는 것이 맞다. 근거 노출과 판단 보류도 이 서비스에서 이미 확인된다. 반대로 화면만 보고 내부 계산·판단 구조가 우리와 같거나 다르다고 단정하지 않는다.

### 컨셉 검토 의견 — 확정 아님

- MBTI 추가, 근거 펼치기, 월별 알림만으로 경쟁 우위를 입증했다고 볼 수 없다. “두 개의 나”와 “절기 연재·회고”도 수요를 확인할 후보로 남긴다.
- 먼저 비교할 후보는 **“내가 주인공인 2027 — 짧은 장면과 선택으로 읽는 신년운세”**다. 사용자 관심사 → 올해의 주제 → 갈림길 장면 → 선택에 따른 다른 대응 장면 → 해석 근거 → 저장할 한 장 순서. 등장 사건은 창작 예시임을 표시하고 미래에 일어날 사실로 쓰지 않는다.
- 선택은 이야기의 대응과 실천 내용을 바꾼다. 같은 출생 입력의 계산 결과를 선택에 맞춰 바꾸거나 MBTI를 근거로 진짜 성격을 판정하지 않는다.
- 합성 사례 하나로 대화형·짧은 리포트형·선택형 장면을 비교해 끝까지 보는지, 기억하는 내용이 무엇인지, 저장·공유하고 싶은지 확인한다. 12화 운영과 알림 개발은 첫 경험의 매력을 확인한 뒤 범위를 정한다.

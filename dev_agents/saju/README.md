dev_agents 실습 폴더. 둘이서은퇴 제품과 관계없다. 타로는 `../tarot/`.

| # | 결정 |
| --- | --- |
| 목적 | "진짜 그럴듯한" 신년운세. 마감 없음, 품질 우선 |
| 공개 범위 | lifecanvasLab 사내 PoC (오픈베타플랫폼 v2) |
| 강의 | 인프런 「전문 사주팔자 AI Agent」는 수강하지 않음. 공개 소개 페이지의 구조(n8n 조율 + Python 계산 + 분석별 에이전트)만 아이디어로 참고, 자료 복제 없음 |
| 화면 | 웹(모바일·PC 반응형). 계산·해석은 화면과 분리해 나중에 독립 에이전트로 뗄 수 있게 |
| 구성 | 하나의 "신년운세" 서비스, 입구 두 개: 사주(리포트형) / 타로(대화형). 계산 서버·LLM 연결 공유 |
| 순서 | `research/` 조사 → `PLAN.md` → 구현 |
| 책임 분리 | 간지·명반·행성 위치·획수는 Python 코드가 계산. LLM은 해석 문장만 |
| n8n | 입력 → 계산 → 해석 → 리포트 흐름이 n8n 화면에 보이게(시연). LangChain은 n8n AI Agent 노드로 대신. 최종 구조는 `research/05` 비교 후 확정 |
| 개인정보 | 저장하지 않음. 리포트는 이미지/PDF 저장만 |
| LLM | Gemini로 시작, 교체 가능하게 |
| 리포트 | 2027 丁未년 중심: 총평·키워드 → 월별 흐름 → 일·관계·컨디션·재물 → 5렌즈별 근거. 구체적 투자·의료 조언 없음 |
| 입력 | 출생 시각 "모름" 허용(해당 렌즈는 잠금), 이름 한자 선택, MBTI 16개 중 선택 + "모름" |
| 나쁜 운 | 솔직히 말하고 "그래서 이렇게 하면 된다"로 끝낸다 |
| 근거 노출 | 문장마다 접힌 근거(예: 丁未 세운 → 정관 → 평가받는 해) |
| 검증 | 포스텔러·점신과 원국·대운 일치 자동 테스트 + 동료 체감 점수 |
| 구조 | 본체는 FastAPI 안 Python 하네스(계산·해석표·LLM 단계·근거 검증·재시도). n8n은 같은 단계를 노드로 보여주는 시연·연결 창구 |
| 1차 범위 | 2027 신년운세만. 평생 리포트(타임라인·직업·관계·MBTI 상성 등)는 2차, 자산·헬스케어는 문구 별도 검토 |
| 입력 화면 | 네이버식 한 화면(성별·양/음/윤·생년월일·12지시/모름). 야자시 등 학파 설정은 접어둠 |
| 결과 첫머리 | 계산 결과를 크게 보여주는 세로 슬라이드 5~7장 + 마지막 "2027 한 장 요약" 공유 카드. 생성 이미지 없음. 웹툰은 2차 |
| 상품 연결 | 넣지 않음 |
| 학파 기본값 | 포스텔러·점신과 같은 쪽(대조 입력 10건을 앱에서 캡처해 정답표로 고정). 다른 학파는 설정 |
| 점성술 엔진 | skyfield(MIT) + 자체 하우스 계산, Swiss Ephemeris 결과와 대조 테스트 |

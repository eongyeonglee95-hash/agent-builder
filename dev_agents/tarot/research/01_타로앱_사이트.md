# 01. 타로 앱·사이트 조사

- 조사일: 2026-10-30 (아래 모든 "확인일"은 이 날짜)
- 범위: 국내·해외 타로 앱/사이트와 AI 타로 서비스, "2027 신년운세" 타로 입구 설계용
- 표기: **확인** = 출처에서 직접 읽음 / **2차** = 블로그·기사 등 간접 출처 / **미확인** = 찾지 못함. 지어낸 내용 없음
- 한계: Playwright 브라우저가 다른 세션에서 사용 중이라 화면을 직접 눌러 보지 못했다. 앱 안 화면(카드 셔플 애니메이션 등)은 앱스토어 설명·기사·웹페이지 글로만 확인했고, 스크린샷(`img/`)은 없다. 앱 안에서만 보이는 흐름은 대부분 "미확인"으로 남겼다.

### 1-1. 헬로우봇 (DLT Partners)
- 출처: App Store https://apps.apple.com/kr/app/id1294957719 (확인일 2026-10-30)
- **확인**
  - 사주·타로 콘텐츠 200개 이상을 "평생 무료 제공"한다고 소개. 타로 예: "이별 후 그 사람의 속마음과 재회 가능성을 타로로 살펴보고"

  - 리뷰 칭찬: "정말 정말 소름이 돋을 정도로 꽤나 잘 맞아요!", 타로가 "아무렇게나 찍어버리는 게임같은" 것이 아니라는 평. 화면에 보이는 리뷰는 4개뿐이라 대표성 낮음
- **2차**: 앱 설명에 "타로 카드로 알아보는 미래의 연인" 기능, 13세 이상 등급(태국 스토어) — https://apps.apple.com/th/app/id1294957719 (검색 결과 요약)

## 4. 종합

### 4-1. "그럴듯함"을 만드는 요소 (조사에서 반복해 보인 것)
1. **내 손으로 고른다는 느낌**: Trusted Tarot "Click on the cards", 타로AI의 셔플+컷, 유튜브 픽어카드, emilytarot의 "내 실물 덱으로 뽑기"(03 문서). 결과가 같아도 고르는 행위가 몰입을 만든다
2. **시작 의식**: 마음속 질문 떠올리기, 문구 소리 내 읽기(Trusted Tarot). 1~3초짜리 "숨 고르기" 단계
3. **자리(위치)별 의미**: 같은 카드도 "과거 자리의 탑"과 "미래 자리의 탑"을 다르게 씀(Trusted Tarot). 일반 카드 설명 복붙이 가장 가짜처럼 보인다
4. **카드 그림 속 디테일 언급**: 03 문서의 공개 프롬프트도 "카드 그림 속 인물의 동작·방향·분위기"부터 말하라고 지시. "이 카드엔 번개 맞은 탑에서 사람이 떨어집니다"처럼 그림을 짚으면 신뢰가 오른다
5. **질문 맥락을 다시 불러주기**: 사용자가 쓴 질문 단어를 해석 문장에 넣기
6. **나쁜 카드도 솔직히**: 안심 → 무엇이 끝나는가 → 할 일
7. **분량과 구조**: 포스텔러 "200쪽", 월운 흐름. 신년 상품은 "한 해를 다 덮었다"는 느낌이 중요
8. **기록**: Labyrinthos 저널·통계. 다시 볼 수 있어야 "내 리딩"이 된다
9. **반대로 가짜처럼 보이는 것**: 매번 긍정적, 질문과 무관한 일반 문장, 주제에 맞춰 카드가 뽑힌 듯한 결과(LLM이 카드를 고를 때), 딱딱한 AI 말투(틱톡 AI 점술사)

### 4-2. 신년(연간) 타로에 어울리는 스프레드

**제안(우리 판단)**: 기본은 **"올해의 카드 1장 + 분기 4장 + 조언 1장" 같은 짧은 연간형(5~6장)**, 원하면 "12개월 전체 펼치기"로 확장. 이유: 13장은 나쁜 카드 비율이 높고 모바일 한 화면에 안 들어감. 최종 장수·자리 이름은 제품 결정 사항.

### 4-3. 따라 할 UI 패턴
- 질문 입력은 **선택 사항** + 예시 칩("2027년 나의 한 해", "이직", "연애", "돈") — 빈 칸 부담 줄이기
- 숨 고르기 1단계(짧은 문구, 3초) → 셔플(누르고 있는 동안 섞임) → 부채꼴로 펼친 뒷면 중 N장 탭 → 한 장씩 뒤집기
- 역방향 사용 여부를 설정에서 끌 수 있게(Labyrinthos, Trusted Tarot). 기본값은 제품 결정 사항
- 결과: 카드 그림 + 이름 + 자리 이름 + 정/역 + 2~3문장 → 다 본 뒤 전체 흐름 요약 → "올해 할 일 3가지"
- 후속 질문 버튼 2~3개(예: "3분기를 더 자세히", "이 카드가 일에서는?") + 자유 입력
- 리딩 저장·다시 보기(저널)

### 4-4. 피할 것
- 깜빡이는 구독 홍보(Labyrinthos 리뷰 불만), 광고 과다(점신 리뷰 불만), 느린 터치 반응(점신·포스텔러 리뷰)
- LLM이 카드를 고르게 하는 구조(주제에 맞춘 듯한 결과 → 가짜 느낌, 03 문서)
- "댓글 달면 행운" 류 낚시 문구(틱톡 AI 점술사)
- 사람 상담사로 넘기는 결제 유도(점신 모델) — 사내 PoC 성격과 맞지 않음(우리 판단)

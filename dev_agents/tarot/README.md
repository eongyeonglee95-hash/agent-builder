# 타로 Agent — 2027 신년 타로 (대화형)

dev_agents 실습 폴더. `../saju/`와 같은 "신년운세" 서비스의 두 번째 입구다. 공통 결정(공개 범위, 웹 화면, LLM, 개인정보 미저장, 나쁜 운 표현)은 `../saju/README.md`를 따른다.

## 타로만의 원칙

- 카드 뽑기(무작위)와 카드 의미표는 코드·데이터. LLM은 질문 맥락에 맞춘 해석 문장만
- 나쁜 카드도 솔직히, 대응 행동으로 마무리 (실제 죽음 아님 → 무엇이 끝나나 → 할 일)
- 신년 타로 6장: 올해의 카드·일·관계·컨디션·돈·조언. "12개월로 펼쳐보기"는 선택
- 서버가 78장 순서를 먼저 정하고 사용자가 탭한 자리를 공개. LLM은 카드를 고르지 않는다
- 같은 질문은 하루 한 번. 카드 번호만 기기에 남겨 다시 열면 같은 카드
- 덱은 1909 RWS 원본 퍼블릭 도메인 스캔(보정 전). "Rider-Waite" 이름은 쓰지 않는다. 의미 문장은 Waite 원서를 근거로 새로 쓴다
- 위기 질문은 리딩 중단 + 109 안내, 건강·법률·투자는 결과 예측하지 않음

## 시안 요약 (결정 전)
트래킹 탭 안을 위에서 아래로 **시장 띠 → 팔로잉 보드(카드/표/히트맵) → 단지 상세 → 주간·월간 리포트**로 바꾸는 안. 좌측 단지 목록은 없앤다. 갈아타기 계산(격차·더 필요한 돈)은 단지 상세 맨 아래 접힘과 갈아타기 탭으로. 색은 사이트 토큰 `--up`(빨강)/`--down`(파랑)만 쓰고 거래유형은 탭으로 구분. 결정 항목 5개(기본 보기, 띠 항목, 리포트 요일, 격차 숨김 범위, 구현 담당)는 시안 페이지 끝에.

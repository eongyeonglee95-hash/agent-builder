# 둘이서은퇴 작업 백로그

앞으로 할 일과 다음 행동을 모으는 시작점. 마지막 정리: 2026-11-15.

## 사용 방법

1. 시작할 때 이 파일과 [인계 기록](docs/DEV_HANDOFF.md)을 읽고, 사용자 요청에 해당하는 작업을 고른다. 목록 순서는 실행 승인이 아니다.
2. 새 요청은 고유 ID·목적·다음 행동·완료 조건을 적는다. 작은 작업은 한 항목으로 끝내고 큰 작업만 나눈다.
3. 착수할 때 담당과 수정 경로를 남긴다. 공통 파일은 인계 기록에 먼저 한 줄 적는다.
4. 종료할 때 완료 근거 또는 남은 일과 막힌 이유를 기록한다. 구현·자동 검증·사용자 확인·실데이터 연결은 구분한다.
5. 검증까지 끝난 작업만 `[x]`로 바꿔 완료 기록으로 옮긴다. 보류 작업은 사용자 재개 요청 전 실행하지 않는다.

기존 작업의 상태·담당·검수 근거 원본은 [AGENT_DESIGN §0](docs/AGENT_DESIGN.md#0-현재-실행-계획협업--2026-10-27-사용자-승인)이다. 아래는 그 기록에서 뽑은 **남은 행동**이며 전체 작업표를 복제하지 않는다. 기존 ID 작업을 진행하면 원본을 갱신하고 이 파일의 다음 행동도 맞춘다. 신규 작업은 여기서 관리하고, 상세 실행 계획이 필요해 작업표에 등록할 때 같은 ID로 연결한다. SHARE-02~07의 Shrimp 운영은 기존 지침을 따른다.

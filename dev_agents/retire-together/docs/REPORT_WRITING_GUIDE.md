# 보고서 문장 작성 규칙

연금·부동산 등 모든 AI 보고서의 공통 기준이다. 이 파일을 실제 AI 요청에 읽어 넣는다. 표현 수정은 여기서 관리하며, 예시의 계좌 상태나 숫자를 사실로 복사하지 않는다.

## 읽자마자 이해되는 문장
- 독자는 금융 전문가가 아니다. 일상적인 한국어와 짧은 문장으로 쓴다. 해요체를 쓰되 모호한 비유나 과도한 친근함을 쓰지 않는다.
- 한 문장에 한 가지 판단만 쓴다. 서로 다른 계좌의 조건을 긴 한 문장으로 압축하지 않는다.
- 결론 → 근거 → 다음 행동 순서로 쓴다. 행동에는 어느 계좌에서 무엇을 어떻게 할지 명시한다.
- 제목은 가장 중요한 사실 하나만 짧게 쓴다. 계좌별 방법과 조건은 요약에서 나눠 설명한다.
- '보강', '교체 여지', '손댈 수 없다', '실행 여력', '노출', '실익'만으로 설명을 끝내지 않는다. 늘리기·팔기·사기·입력하기처럼 관찰 가능한 행동으로 풀어 쓴다.
- 사용자가 선택한 설정과 제도상 불가능을 구분한다. 사기만 설정이면 '현재 사기만으로 설정되어 있어, 납입할 금액을 입력해야 매수 수량을 계산할 수 있어요.'라고 쓴다. '계좌를 조정할 수 없다'고 단정하지 않는다.
- '확인 필요'로 끝내지 않는다. 무엇을 어디서 확인하면 다음 행동을 할 수 있는지 쓴다. 제공되지 않은 화면이나 기능은 만들어 내지 않는다.
- 정보가 없으면 부족한 정보와 그 때문에 정할 수 없는 판단을 구체적으로 쓴다. 근거 없는 명령·확신으로 쉬운 문장을 대신하지 않는다.
- 숫자·상품명·계좌명은 제공 자료에서만 가져온다. 아래 예시를 현재 계좌에 그대로 적용하지 않는다.

## 표현 예시
| 피할 표현 | 바꿀 표현 |
| --- | --- |
| 장기채 보강이 핵심 | 선택한 목표에 맞추려면 장기채 비중을 늘려야 해요. |
| 구계좌는 교체 여지 | 연금저축(구)은 목표보다 많은 자산을 일부 팔고, 그 돈으로 부족한 자산을 살 수 있어요. |
| 신계좌는 추가 납입 없으면 손댈 수 없어요 | 연금저축(신)은 현재 '사기만'으로 설정되어 있어요. 이번에 넣을 금액을 입력하면 무엇을 얼마나 살지 계산할 수 있어요. |
| 교체 실익 검토 | 지금 상품을 유지할 때와 바꿀 때의 비용을 비교해 보세요. |

## 제출 전 자체 점검
1. 금융 용어를 몰라도 뜻이 이해되는가?
2. 어느 계좌의 어떤 상황인지 분명한가?
3. 사용자가 다음에 할 행동이 구체적인가?
4. 설정 때문에 없는 계산을 법적 제한이나 거래 불가로 잘못 설명하지 않았는가?
5. 같은 내용을 반복하거나 한 문장에 여러 조건을 몰아넣지 않았는가?

## 근거와 일관성

[모든 분야 공통 보고서 원칙]
동일한 사실에 적용하는 평가 기준과 출력 순서를 매번 유지한다. 표현을 다양하게 만들기 위한 새로운 논점·경고·권유를 추가하지 않는다.
headline → summary → findings → assessments → alternatives → actions → questions의 구조를 고정한다.
핵심 발견은 생활·재무 목표에 미치는 영향, 실행 시급성, 근거 확실성 순으로 우선순위를 정한다. 알려지지 않은 위험을 확인된 위험보다 앞세우지 않는다.
평가 기준·숫자·가중치·점수는 임의로 만들지 않는다. 확인된 사실, 조건부 해석, 판단 보류를 명시한다.
사용자가 제공한 사실과 모델의 일반적 설명을 구분한다. 출처에 없는 사건·가격·법령·책 내용을 인용하지 않는다.
판단 보류는 불량 판정이 아니다. 판단에 필요한 입력을 구체적으로 적는다.
위험만 나열하지 말고 확인 가능한 강점과 선택의 대가도 설명한다. 전망이나 특정 투자상품 추천으로 변질시키지 않는다.
본문은 전문 용어를 풀어서 한국어로 작성한다. 반복 면책·과장·홍보 문구는 쓰지 않는다.

보고서 표지 제목은 계산된 현재·목표 차이로 짧게 구성한다. AI의 긴 복합 문장을 표지 제목으로 그대로 사용하지 않는다.

## 은퇴 준비 종합 평가
- 첫 요약은 현재 준비에서 잘된 점, 부족한 점, 가장 먼저 할 일 순서로 쓴다. '목표 비중에 맞음'만으로 노후 준비가 충분하다고 판정하지 않는다. 임의 점수나 등급은 만들지 않는다.
- retirement_outlook이 있으면 은퇴 첫해·연금 수령이 모두 시작되는 해·후반기의 생활비와 연금 수령액을 비교한다. 모두 세전·현재 돈 가치이며 가정에 따른 예상치다. 첫해 충족을 평생 충족으로 일반화하지 않는다.
- 추가 납입 시나리오는 코드가 계산한 수치만 사용한다. 비교 가정과 권장액을 구분한다. 가계 현금흐름을 모르면서 특정 금액을 반드시 더 넣으라고 하지 않는다.
- 리밸런싱만으로 수령액이 늘어난다고 말하지 않는다. 이 계산은 선택 ETF의 미래 수익률이 아닌 저장된 수익률 가정을 쓴다.

- 입력 JSON의 키 이름(new_cash, buy_only 등)이나 코드 파일 경로를 독자에게 보여주지 않는다. 각각 추가 납입금, 사기만 설정 등 사용자 언어로 풀어 쓴다.

## 분량 제한 — 이후 작성 시 우선 적용
- 기본 화면은 결론 한 줄 → 핵심 숫자 세 개 → 할 일이다. 제목·요약·POINT에서 같은 결론을 반복하지 않는다.
- 제목 20자 내외, 결론·할 일은 각각 60자 이내의 한 문장을 목표로 한다. 여러 조건을 붙이지 말고 필요한 근거는 별도로 둔다.
- 표에 있는 숫자를 설명 문장으로 다시 나열하지 않는다. 자료의 JSON 키를 언급하지 않는다.
- 질문형 소제목은 짧은 명사형으로 바꾼다. 예: '지금 조금 더 저축하면 얼마나 달라질까요?' → '추가 저축 효과'.
- 강조는 결론과 숫자에만 쓴다. 본문은 짧게, 가정·출처는 작은 글씨, 추가 근거는 접어서 둔다.

## X-Ray 방식의 진단과 적극적 투자
- 숫자 반복 대신 도표 옆에 판단 한 줄과 선택 조건 한 줄을 둔다. 단순 목표 이탈과 투자 적합성은 구분한다.
- 사용자는 적극적 운용도 고려한다. 주식 비중을 늘리는 선택과 현재 비중을 유지하며 납입을 늘리는 선택을 비교한다. 투자 기간, 감내 가능한 손실, 생활비 자금이 근거다. 비중·전략은 사용자 선택 없이 변경하지 않는다.
- ETF 업종·지역·스타일·비용 데이터가 없으면 X-Ray처럼 보이도록 숫자를 만들어내지 않는다. 현재 구현은 등록 자산군 기준이다.

## 종합 진단 첫 장 (2026-11-19)
- 첫 장의 행동은 최대 3개다. 추가 저축 가능액·목표 배분 조정·계좌별 납입금 입력 등 제공된 자료에서 필요한 행동만 고른다. 같은 행동을 다른 표현으로 반복하지 않는다.
- 전체 배분의 의미는 한 문장으로 판단한다. 조건과 근거는 별도 항목에 두어 펼쳐 읽게 한다. 숫자 세 개와 그래프를 문장으로 다시 나열하지 않는다.
- 첫해 생활비 충족과 전 기간 충족을 구분한다. 저장된 가정에 따른 연금 계산이며 일반자산 인출을 포함한 가계 전체 충분성으로 확대하지 않는다.

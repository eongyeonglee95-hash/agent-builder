# 연금탑 · 기존 기능을 그대로 사용하는 디자인 비교

주소: http://127.0.0.1:5180/previews/pension-stone/index.html#pension

## Direction contract
- THESIS: 기존 자산 등록·입력 수정·월 생활비 계획·나이별 수령 시간표를 실제로 조작하는 경험을 보존한다. 별도 가짜 계산기를 만들지 않는다.
- OWN-WORLD: 기존 theme.css와 석탑을 유지한다. 일상적인 가계 점검에서 읽기 쉬운 밝은 요약면, 정렬된 연금층, 또렷한 생활비 계산 버튼을 사용한다.
- STORY: 자산 등록/수정 → 생활비 계산/적용 → 수령 조건 수정/재계산 → 나이별 소득을 슬라이더·그래프로 탐색한다.
- FIRST VIEWPORT: 넓은 화면에서 석탑·층별 등록/수정은 왼쪽, 월 연금·생활비 계산은 오른쪽. 좁은 화면은 요약을 먼저 보여 준다. 받는 시간표는 기존 그래프·나이 표시·슬라이더·이전/다음 조작을 전부 유지한다.
- FORM: seed: none (pinned). 사용자 “자산등록하고 입력수정하고”, “나이별로 막 내가 조정해가면서 보는 재미”.
- FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 구현
- 독립 Vite HTML 엔트리가 기존 `src/main.tsx` 전체를 로드한다. App, AuthGate, 등록 흐름, RetirementPage, 생활비/납입/수령 다이얼로그, API를 그대로 사용한다.
- `live.css`만 이 진입점에 한정하여 적용한다. 기존 메인 화면의 소스·계산식·레이아웃은 변경하지 않는다. 별도 프로덕션 빌드 진입점에 추가하지 않았다.
- 실제 데이터와 연결된다. 사용자가 저장하면 기존 계획/자산에 반영된다. 로그인은 기존 AuthGate를 그대로 통과해야 한다.
- 이전 가상 시안은 `static.html`과 `main.tsx`에 남아 있다. 새 기본 index는 실제 기능을 사용하는 버전이다.
- 임의의 예시 금액을 실제 가계 화면에 삽입하지 않는다.

## 검증 및 한계
- 별도 임시 DB 서버(`web/e2e/server.py`, 포트8879)에만 합성 가족/연금을 등록하여 검증. 실제 가계 데이터에는 테스트 쓰기를 하지 않았다.
- 항목별 생활비 수정 → 합계 666만원 적용 → 실제 API 저장 및 시간표 목표선 6,660,000원 연결 확인.
- 연도 슬라이더 → 부부 나이(65세/68세)와 API 금액 일치, 방향키 조작 확인.
- 사적연금 수령 나이를 61세로 저장 → 서버 재계산의 시작 나이61세 확인.
- 국민연금/퇴직연금 수정, 미래 납입 계획, 공통 자산 등록 창 열기 확인. 사진/파일 업로드·외부 시트 저장은 이번 검증 범위가 아니다.
- 1440px 및 360px 스크린샷 직접 확인, 가로 넘침0, 브라우저 실행 오류0. 캡처는 합성 테스트 자료의 실제 브라우저 렌더이며 생성 이미지가 아니다.
- 기존 모든 기능을 유지하는 만큼 모바일 페이지는 길다. 기능을 숨기거나 삭제해서 줄이지 않았다. 디자인을 기본 화면에 반영하는 결정은 아직 하지 않았다.

## 반응형 배치 수정 (2026-11-18)
- 이전 시안은 viewport 기준 배치와 기존 grid 좌표가 혼재해 중간 너비에서 요약 영역에 큰 빈칸이 생겼다. sidebar를 제외한 실제 콘텐츠 너비의 container query와 명시적 grid 영역으로 바꿨다.
- 층별 금액/설명과 등록/수정 버튼을 넓은 화면에서 나란히, 좁은 화면에서 자연스럽게 다음 줄에 배치했다. 수령 시간표의 중첩 테두리를 정리했다.
- 수동 link 삽입 대신 Vite CSS 모듈 로딩으로 시안 스타일 갱신을 연결했다. 기존 기본 화면과 다른 사용자가 수정한 index.html은 건드리지 않았다.
- 밝은/어두운 앱 설정 각각 320·360·390·600·768·900·901·1024·1200·1280·1440px에서 문서 가로 넘침 및 요약/행 형제 요소 겹침 없음 확인. dark 설정에서도 연금 본문은 기존 앱 정책대로 밝은 화면이다.
- 360·1024·1440 렌더 직접 검토. 격리 임시 DB에서 생활비 적용→목표선, 수령 나이 저장→재계산, 키보드 연도 탐색, 등록/수정/납입 대화상자 재확인.

# 4층 추가연금 문구 간소화

사용자 수락: 기능과 숫자는 유지하고 긴 설명을 짧은 항목명으로 변경한다.

- 연금으로 받기: 4층 월액
- 목돈으로 보유: 4층 등록 목돈
- 4층 포함 월 연금: 기존 1–3층 + 4층의 월액, 별도 구분선으로 표시

RetirementTower에서 공통 ExtraPensionSummary를 사용한다. 원금/월액 계산과 등록·수정·생활비·수령계획 기능은 유지한다. 기본 합계가 미확인일 때 합산 월액은 미확인 표시를 유지하고, 금액 숨김일 때 data-won 속성도 노출하지 않는다.

문구 미리보기: `/previews/pension-stone/extra.html`. 예시 값은 합성 데이터이며 사용자의 실제 금융 수치를 코드/캡처로 커밋하지 않는다. 전체 디자인 비교 진입점은 `/previews/pension-stone/index.html#pension`; 기존 앱 기능을 재사용하는 개발용 별도 진입점이다.

검증: npm --prefix web run build 통과. Chrome에서 360/1280px 문구 시안 확인, 가로 넘침 및 실행 오류 없음. 전체 디자인 비교의 반응형 배치/기능 확인은 이번 대화의 선행 검증에 포함한다. 빌드에는 기존 폰트 @import 및 큰 번들 경고가 남아 있다.

# 서울 구 경계

출처: https://github.com/southkorea/seoul-maps/blob/master/kostat/2013/json/seoul_municipalities_geo_simple.json

통계청 2013 센서스 행정구역 경계의 단순화본. 좌표와 속성은 변경하지 않고 JSON 공백만 제거했다. 현재 행정 경계 또는 법적 경계를 보증하지 않으며 지도 탐색용이다. 원저작자 Lucy Park 및 southkorea/seoul-maps 기여자. 저장소 README가 명시하는 Apache-2.0 라이선스 전문을 동봉했다.

새 C 시안으로2026.11.18 공개 화면 확인

보기 좋은 화면보다, 비교가 이어지는 화면.

부동산지인과 호갱노노의 공개 화면을 브라우저로 열고 검색·필터 구성·단지 상세·차트를 확인했다. 전 기능·로그인 영역·유료 영역을 완전히 검수했다는 의미는 아니다. 아래 ‘관찰’과 ‘우리의 설계 판단’을 구분했다.

직접 확인한 범위

  • 부동산지인 홈: 정보 구조, 지역·단지 검색, 월간 리포트·지표 설명 진입점.
  • 부동산지인 서울 지역 분석: 지역별 매매·전세 비교, 시장강도, 기간별 수급·거래·시세 구성. 첫 캡처에는 로딩 표시가 남아 있어 정지 화면만으로 완전 동작을 평가하지 않았다.
  • 부동산지인 아파트 분석: 강남구 동별 현황, 가격·단지·기간 조건, 4분면, 단지 목록과 비교 진입.
  • 공식 아파트 분석 개편 안내: 여러 지표를 대조하는 멀티차트와 과거 고점·저점 대비 표시를 공식 설명으로 교차 확인.
  • 호갱노노 홈: 검색·필터·분석 도구. ‘은마’ 검색 후 대치동 은마로 이동.
  • 호갱노노 은마 상세: 평형별 가격 시계열, 계약일·층을 갖춘 거래표, 매물, 재건축, 세금 조건, 입지와 주민 리뷰 요약까지 확인.

호갱노노 지도 타일은 이 환경에서 네이버 지도 로딩 오류로 보이지 않았다. 검색과 단지 상세는 접근 가능했다. 단지 상세의 비교 탭도 직접 전환했다. 관심 알림의 실제 저장·발송, 로그인 이후 기능, 유료 기능은 검증하지 않았다.

가져올 것과 줄일 것

관찰도움이 되는 이유새 C에서의 적용
지인: 조건 필터 → 단지 목록 → 비교 차트지역 전체에서 후보를 좁히고 동일 조건으로 대조한다.관심 목록과 전체 탐색을 분리하고, 행 선택이 차트·검토 노트를 함께 바꾼다.
지인: 매매·전세·거래·매물 지표를 분리가격과 거래 활성도를 같은 의미로 취급하지 않는다.유사군 가격, 과거 고점, 거래 건수, 관심도를 별도 근거로 둔다.
호갱노노: 단지 상세에서 차트와 거래표를 연결추세 아래의 실제 거래 조건을 확인할 수 있다.단지·평형·기간을 고정한 차트와 수치 표, 후보별 거래 건수·날짜를 같이 제공한다.
호갱노노: 가격 외 세금·재건축·입지·리뷰낮은 가격을 설명하는 조건이 드러난다.AI의 반대 근거와 중개사 질문을 가격 바로 옆에 둔다. 개인별 세금은 추후 조건 기반 계산으로 연결한다.
두 서비스의 넓은 정보 범위와 많은 진입점탐색에는 유용하지만 개인의 다음 행동을 직접 정해주지는 않는다.광고·일반 순위·다수 지도 도구를 첫 화면에서 제외하고 자금→선택 단지→검증 근거 순으로 배치한다.

위의 ‘도움이 되는 이유’와 ‘적용’은 우리의 설계 판단이다. 두 서비스의 기능을 그대로 복제하거나 데이터를 자동 수집했다는 의미가 아니다.

‘저평가’는 하나의 점수가 아니다

  • 상대 가격: 같은 생활권·면적·연식·단지 규모·거래 시점·층 조건의 비교군을 먼저 만들고, 가격 차이가 조건 차이로 설명되는지 본다.
  • 과거 위치: 전고점 회복률은 과거와의 거리다. 전고점을 회복해야 적정가가 되거나, 미회복이면 저평가라는 결론은 내리지 않는다.
  • 거래 활성도: 완료된 기간의 거래 건수를 이전 기간과 비교하고, 해제·중복·신고 지연·단지 규모를 고려한다.
  • 시장 협상력: 지인의 시장강도를 매수우위 지수와 동일시하지 않는다. 지표별 정의와 지역 범위를 확인하고 수급·거래·매물의 근거가 일치하는지 본다.
  • 관심도: 조회·검색·알림 수는 보조적인 관심 신호다. 실제 매수 수요나 저평가의 대용 지표로 쓰지 않는다.
  • 내 자금: 합산 순자산은 가용 현금과 다르다. 매도 대상·시점·대출 상환·보증금 반환·세금·비용을 반영해야 매수 예산이 된다.

API를 연결할 때의 역할

코드가 거래 정리·기간별 수치·비교군·자금 계산을 확정하고, AI에는 근거가 붙은 결과만 전달한다. AI 응답은 관찰된 변화, 이를 뒷받침하는 원문, 반대 설명, 확인할 질문으로 제한한다. 자료가 없으면 빈칸을 추측으로 채우지 않는다.

주간에는 새 변화·매물 확인·제도 발표, 월간에는 누적 추세·지난 가설·시행 예정 세금과 자금 조건을 다시 검토한다. 주택 수·보유/거주 기간·지분·계약 순서를 적용 조건으로 관리한다.

현재 시안은 가상 자료로 상호작용만 구현했다. AI API, 실제 장부·전체 아파트 목록·가격 수집·로그인 저장·자동 리포트는 연결하지 않았다.

다음 검증이 필요한 부분

전용면적별 실존 단지 목록, 취소 거래 정리와 층 조건 보정, 매물 중복과 가격 이력, 비교군의 적합성, 순자산과 실제 매수 예산의 분리, 원문·관측일을 가진 AI 응답 검증이 필요하다. 현재의 가상 가격이나 후보 순서를 매수 판단에 사용할 수 없다.
